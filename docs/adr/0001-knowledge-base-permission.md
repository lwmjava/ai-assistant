# ADR-0001 知识库权限语义

> 状态：**Accepted**  
> 任务：`RAG-002`  
> 批准日期：2026-09-13  
> 批准人：产品负责人（本仓库个人开发者）  
> 风险：L2  
> 实现任务：`RAG-006`（2026-09-19 已落地 `RAG_KB_SCOPE`；默认 `tenant`，`uploader` 回滚）

## 1. 背景

当前知识库同时存在两套可见性：列表/详情/删除按上传者过滤，检索/Agent 按租户过滤。同租户用户 B 可能检索到列表里看不到的文档。

## 2. 事实

| 声明 | 证据 |
|---|---|
| 列表对非管理员按 `user_id` 过滤 | `RAGService.list_documents` |
| 详情/删除走 `_can_access`（非管理员必须是上传者） | `RAGService._can_access` |
| 检索只传 `tenant_id` | `RAGService.search` |
| 向量检索按租户 + 当前版本 | `app/rag/vectorstore/local.py` |
| 当前不一致已由表征测试锁定 | `tests/test_rag_permission_semantics.py` |

## 3. 决定

选择 **选项 A：租户共享当前版本**。

读路径（列表、详情、检索、Agent Context）对齐为：具备 `knowledge_bases:read` 的用户可见**同租户 `is_current=true` 的文档**。跨租户禁止。旧版本不进入列表、检索和 Agent。

写路径（删除、重解析）采用保守默认（批准选项 A 时一并固定，因原确认项未单独回复）：

- 普通成员：只能删除/重解析自己上传的文档。
- `tenant_admin` / `system_admin`：可删除/重解析同租户当前文档。
- 跨租户：禁止。

资源级 ACL 列为 `Planned`，不阻塞本阶段 Evaluation。

未选 B（上传者私有/ACL）和 C（维持现状）。

## 4. 批准后权限矩阵（2026-09-25 修订，RAG-011）

控制面与检索面分开。本修订只覆盖知识库列表、详情、删除、重解析。不改用户、审计产品和其他资源的跨租户规则。资源级 ACL 仍为 Planned。

| 动作 | 普通成员 | 租户管理员 | 系统管理员 |
|---|---|---|---|
| 列表 / 详情 | 仅自己上传且 `is_current=true` | 本租户全部版本 | 任意租户全部版本 |
| 删除 / 重解析 | 同上 | 本租户全部版本 | 任意租户全部版本，跨租户写 `audit_event` |
| 检索 / Agent | 本租户当前版（含他人上传） | 同左 | 同左，不因跨租户放宽 |

`RAG_KB_SCOPE=uploader` 只保留为成员当前版列表的回滚开关。管理员控制面始终能看到历史版。重解析就地更新分块，不改变 `is_current`。同一 `version_group_id` 仅一个当前版。删除是软删除：写入删除时间，保留期 90 天；成员和检索看不到已软删文档，管理员可以查看；期满后再物理清理并再次审计。

## 5. 后果

- 检索行为保持租户范围；列表/详情变宽，与对话命中一致。
- 同租户成员能读到他人上传的当前资料。私有文档需求走后续 ACL。
- 导入任务列表应与文档列表读语义对齐（`RAG-006` 一并改）。

## 6. 迁移

1. `RAG-006` 增加 Feature Flag `RAG_KB_SCOPE=uploader|tenant`，默认 `uploader` 保持旧列表。
2. 改 `list_documents`、`_can_access`（读）、导入任务可见性；删除/重解析按上表写权限。
3. 把表征测试改成 To-Be 期望，并补跨租户为零泄露。
4. 打开 `tenant`，观察后再删除 `uploader` 路径。

不迁移已有文档行；`tenant_id` / `user_id` / `is_current` 字段保持。不删除业务数据。

## 7. 测试计划（实现于 `RAG-006`）

| 编号 | 场景 | 期望 |
|---|---|---|
| KB-01 | 用户 A 上传，用户 B 同租户列表 | B 可见该当前文档 |
| KB-02 | 用户 B 详情 / 检索 / Agent | 可见且可命中 |
| KB-03 | 用户 B 删除 A 的文档 | 成员拒绝；租户管理员成功 |
| KB-04 | 跨租户列表、详情、检索、Agent | 全部不命中 / 拒绝 |
| KB-05 | `is_current=false` | 不出现在列表和检索 |
| KB-06 | 删除后 | 列表与向量均不可见 |

`tests/test_rag_permission_semantics.py` 锁定 To-Be：同租户当前文档可列表/详情/检索，跨租户不命中。测试使用隔离 SQLite，避免共享测试库历史文档干扰 top-k。`uploader` 回滚见 `tests/test_rag_access.py`。

## 8. 回滚

将 `RAG_KB_SCOPE` 设回 `uploader`。索引无需重建。不删除数据。

## 9. 2026-09-19 评测口径确认（A1）

产品确认：在资源级 ACL 仍为 `Planned` 期间，评测**不得**把「同租户当前文档被检索到」记为越权。
`rag-036` / `rag-037` 的门禁改为生成层不得返回答案点（如 `NW-HR-001`）。
`rag-026` 命中内部备忘不是权限失败，生成层应澄清且不得用内部备忘冒充对客承诺。
本确认不改变第 3 节决定，也不提前实现资源 ACL。
