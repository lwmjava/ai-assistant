# ADR-0005 RAG 结构切分、LLM 辅助与模型上下文预算

> 状态：**Accepted**（架构批准，能力尚待逐卡实现）
> 创建日期：2026-10-05  
> 批准日期/批准人：2026-10-05，用户/本项目负责人
> 风险：目标实现涉及 L2（派生数据持久化、模型调用与索引切换）；架构批准不授权真实数据迁移或生产启用
> 设计：[RAG 自适应切分与上下文设计](../plans/design_rag_adaptive_context_20261005.md)  
> 任务关系：RAG-021/022 结构与路由、028 模型预算、029/030 上下文、031 LLM 边界、040 章节摘要；见整改拆分计划

## 1. 背景与事实

用户上传的 Markdown ASCII 盒图被切断，parent_child 与 structured 均出现内容不完整。parent_child 默认 paragraph 对超长段硬切；structured 标题下正文仍按句子/字符拆分。现有 semantic 以相邻句子向量相似度切分，不保护完整结构。

RAG 上下文固定按字符裁剪，未根据所选生成模型窗口计算预算。LLMProvider 没有窗口契约；max_tokens 是输出限制。知识库大章节没有摘要能力，Memory 摘要仅处理对话历史。代码证据：app/rag/chunking/、app/rag/ingestion.py、app/rag/context_merge.py、app/llm/base.py、app/memory/。

## 2. 选项

| 选项 | 收益 | 代价/限制 |
|---|---|---|
| 仅结构保护 | 快、确定性、无新增模型成本 | 不覆盖主题边界、大章节概览与模型预算 |
| 结构驱动自适应 + 受控 LLM 辅助 + 预算 | 完整性可验证、按需语义处理、可分阶段关闭 | 需要能力配置、来源范围、摘要生命周期与评测 |
| LLM 决定全部边界 | 对无结构正文有理解能力 | 波动、费用、延迟、超窗和原文改写风险，需要独立硬校验 |

## 3. 决定

采用第二项，具体约束：

- 结构保护先于软块大小；超过模型硬限制明确拆分/oversized，不能无条件保留整章。
- 父块先建，子块在父块内部生成；保存来源范围、切分计划与版本。
- LLM 只建议合法边界；原文由代码按范围提取，非法/失败回退规则。
- 章节摘要是可选、版本绑定的派生数据，原文仍是事实与引用依据；首先按原文命中关联取摘要，不另建摘要检索系统。
- 模型能力来自版本化配置，生成与 Embedding 限制分开；未知模型无经批准配置时拒绝调用。
- 服务先授权取证据，纯 Context Builder 组装；每次实际 LLM payload 经 Budget Guard 校验，包含工具与质量检查阶段。
- 完整保留不可信围栏；来源输出与实际选入上下文一致，不把检索命中等同答案引用。
- 不重写 Runtime，不改变现有 ACL、向量库默认值、Embedding 模型与检索公式。
- LLM 边界辅助和章节摘要默认关闭；chunk size 是软目标，未超经验证 Embedding 硬限的代码/盒图完整保留；表格按完整行切并带表头。无法安全拆分的超长结构保留原文、标记 oversized、明确未向量化原因，不静默硬切。允许导入结果明确呈现部分内容待处理，不能伪称完整入库。

## 4. 边界、后果与安全

本决定改变 RAG 与 Harness 上下文职责，故先 ADR。Context Builder/Guard 作为现有链路内可测试组件，不能直接访问数据库；Service 管理身份、版本、持久化与原子切换。摘要/父块关联不得绕过过滤。

收益是切分完整性与输入预算可追踪；代价是额外模型调用、派生数据与索引兼容管理。LLM 摘要有事实遗漏/幻觉风险，需原文回查与真实 Evaluation；确定性结构校验不能替代语义质量验证。关闭可选 LLM 能力仍可规则检索。

## 5. 迁移与兼容

先实现规则结构保护，再自适应路由，再模型预算，最后 LLM 边界与摘要。已上传文档不自动重建；明确授权重解析才产生新切分版本。源文件保留，旧版本准备完成前继续服务；外部索引需独立验证切换与补偿。新增 API/config/schema 按项目同步要求落盘；不在本 ADR 执行数据库迁移。

## 6. 验证与准入

确定性验证结构不破坏、原文无丢失/乱序、父子归属、预算/围栏、源引用、租户/版本/删除、失败降级与旧版可用。真实评测固定 Embedding/检索变量，分别评价切分、LLM 辅助、摘要；记录模型/Prompt/数据/计数器版本与延迟成本，不改冻结报告、不用 Mock 宣称质量、不用 holdout 调参。

生成质量阈值、未知模型能力配置及摘要启用授权须在实现前由负责人确认并写入计划；未确认不得生产启用。ADR Accepted 也不代表 Implemented，各阶段须独立验收。

## 7. 回滚

2026-10-06 搜索展开边界补记：RAG-016 的初始命中数量受 top_k 限制，关联父块展开可增加数量；真实命中父块保留自身评分和 similarity，仅展开的父块继承触发子块评分。结果保留命中顺序并插入关联父块，不声明最终混合列表经过独立重排。授权、版本与注入复核在搜索返回前执行；批量 SQL 减少 N+1，但并未迁移到 AsyncSession。父块全文搜索展示不等于对话上下文选入，后者的预算由 RAG-030 承接；切分碎片及章节结构由 RAG-021 承接。

独立关闭边界辅助与摘要，恢复已验证的规则与预算配置；预算硬护栏保留。切分回滚使用旧计划/旧索引，重要数据重建另行批准。保留兼容来源字段与旧文档读取路径。

## 8. 决策状态

2026-10-06 结构保护输入护栏补记：用户批准 RAG-021 扩展 app/rag/service.py 与 app/rag/embeddings/。核对实际 DashScope text-embedding-v3 后，用户明确批准使用 UTF-8 字节数 + 32 预留作为保守估算并以合成样本校准；每输入上限 8192 tokens、batch 10 的依据为厂商同步接口说明（核对日期 2026-10-06）。该估算不称精确 tokenizer 或全输入数学保证；六类合成样本的实际 API usage 校准只证明已观测样本。未知端点/模型无明确政策时不外发；超限原文保留与未向量化原因分开记录。模型通用能力、生成预算仍归对应后续卡；本补记不批准更换 Embedding 模型、真实索引重建或生产启用。计划与证据见 [RAG-021 实施计划](../plans/plan_rag_021_structure_integrity_20261006.md) 及 [实现说明](../plans/implementation_rag_021_structure_integrity_20261006.md)。API/README 呈现范围随后由用户明确批准，接口与契约验证已完成；人工业务验收未完成，不能将整个任务写成 done。

2026-10-06 父子关系缺陷修复：parent_child 的子块从对应父块内容内部生成，禁止以全文父子块数量平均分配关联。该修复不表示结构感知切分阶段完成；原父策略和子策略仍可按既有方式切分。旧文档不自动迁移，用户明确重建后更新关联和块 ID；重要索引或生产重建仍需单独授权。

初稿阶段用户只授权设计与 ADR，因此当时为 Proposed。用户于 2026-10-05 在多 Agent 推进对齐后明确批准本 ADR 分阶段实施及上述 oversized 行为，现改为 Accepted。既有 RAG-021～040 相关卡及整改拆分计划承接实现，每次一张。批准不等于 Implemented，不授权真实索引重建、生产迁移、新供应商外发；真实模型清单、调用上限、质量门禁及摘要保留生命周期仍在对应卡确认。权限另遵 ADR-0001 第 10 节，不能以预算架构批准代替权限修订。

## 9. 2026-10-06 预算、来源、评测与摘要裁决批准

批准人：用户/本项目负责人。批准来源：[推进清单第 8～9 节](../plans/plan_rag_remaining_order_20261006.md)。本节更新上一节尚待方向裁决的描述，数值和具体执行范围仍按以下条件明确。

- RAG-028：provider/model/deployment 的能力版本化；优先适用官方计数器，缺少时采用经校准保守估算并明确局限；未知模型无批准配置拒绝。021 的特定 Embedding 护栏沿用，不能当成全部生成预算已实现。
- RAG-029：系统/安全指令及当前问题优先保留，先扣输出预留；历史、工具和 RAG 在显式预算内组装。知识问答优先保留相关完整证据，先缩减无关/较旧历史；不能安全装入时明确超限或证据不足，不截坏块/围栏。selected 只表示实际选入，逐答案点引用正确仍由 RAG-035 评价。
- 模型/样本/费用：优先既有已授权供应商和公开/合成/确认脱敏样本；分别登记用途和外发范围，AI 生成不升级 Gold。单卡提出调用/token/费用上限，超限停止。当前没有批准新的具体金额、未核对模型配置、新供应商或真实客户文档外发。

- RAG-037 的知识问答/普通聊天方向已于 2026-10-05 批准，具体错误和拒答契约据此落盘，不重复询问同一方向。038 的常规时限/重试上限由实现计划提供依据；新增降级架构才另裁决。

上述决定按单卡依赖实施，不立即创建派生数据或运行真实模型。权限核验遵 ADR-0007；索引身份遵 ADR-0008。恢复/迁移/外部状态不新增旁路，CI/OPS 阻塞与三个 Deferred 按批准记录继续保留。
