# ADR-0008 Embedding 索引身份与受控切换

> 状态：**Accepted**（治理方案批准，功能仍 Planned/Partial）
> 日期/批准人：2026-10-06，用户/本项目负责人
> 实现任务：RAG-032；后续 RAG-015/036/019
> 批准来源：[推进清单第 8 节及批准记录](../plans/plan_rag_remaining_order_20261006.md)
> 风险：L2；真实重要数据重建/生产切换另授权

## 背景与事实

现有维度检查不能阻止同维异模型混用；健康检查展示模型也不等于索引身份验证。ADR-0002 正式目标为 Milvus，当前默认 local。RAG-022 的 Local 重解析保护不能证明 SQL/远端索引的跨系统原子性。

## 选项

1. 原索引原地改模型/补写：混用风险高、难回退（不采纳）。
2. 新索引准备、校验、显式切换、保留旧索引（采纳）。
3. 新建双写或队列平台：超出当前治理边界（不采纳）。

## 决定

- 索引绑定 provider、model、deployment/修订标识（存在时）、维度、索引版本，以及实际影响向量的规范化/metric 约定；不存密钥或连接串。
- 写入与查询均核对索引身份，同维异模型禁止混用；历史索引缺身份时不能自动认定与当前配置兼容，需要单卡制定有证据的登记/重建路径。
- 更换模型使用新索引/collection。准备期间旧索引继续读取；新索引完成数量、身份、授权、检索与故障校验后才显式切换。
- 切换必须可追踪目标和版本，失败保留旧读路径。旧索引保留用于回退，不随切换自动清空；保留与删除操作需明确批准策略。
- 缓存绑定检索权限和索引身份；切换、发布、删除、重解析及改权触发失效/重新授权，不能继续复用旧结果。
- 临时库/测试 collection 先验证。真实知识库重建另明确数据范围、备份、影响和执行授权；本决定不自动运行 schema 迁移、改默认向量库或更换模型。
- 沿用已批准 Milvus cosine；Local/Milvus 分数和混合语义由 RAG-015/036 独立证明，不修改冻结 Local 基线。外部写入/清理失败须显式记录及按已批准方案补偿，不宣称跨库事务已实现。

## 后果、迁移与兼容

需要索引登记和新旧数据并存容量。具体存储结构、切换接口、故障状态及补偿机制在 RAG-032 单卡计划落盘后实现；不为本次批准引入新队列、供应商或平台。回退路径必须具有对应模型能力配置，不能只改 collection 名称后仍用新模型查询旧向量。

## 验证

同维异模型写/查拒绝；未知旧身份拒绝混用；新索引准备失败旧版仍可读；身份与数量校验；切换故障、回退模型配套、缓存失效、跨租户及删除/重解析切片。真实质量报告记录 provider/model/维度与索引版本，Mock 不证明质量或 Milvus 生产可用。

## 回滚

停止新索引准备/写入，显式恢复旧索引及其配套模型与配置，重新授权/失效缓存；保留新旧数据与审计证据。重要数据清理另授权，不能通过代码回退删除索引或文档。
