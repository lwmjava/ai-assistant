# ADR-0014：技能快照、运行时工具约束与恢复绑定

状态：**Accepted**，用户明确批准“按该计划、允许路径及 ADR-0014 开始实现”。日期：2026-10-19。任务：V1C-003。相关：ADR-0004、ADR-0010、ADR-0011；具体方案见[实施计划](../plans/plan_v1c_003_20261019.md)。

## 背景与事实

技能选择已隔离私有/全局并提供effective_version；默认/fast已有Prompt注入。Supervisor未消费技能；工具模式绑定未进入对话执行政策。checkpoint不含技能来源和版本，重新匹配不能证明恢复旧计划仍使用当前授权技能。单纯过滤registry也不能约束已注入原registry的执行器与结构化计划。

## 选项

- A：显式请求内快照；当前工具政策与绑定交集；Supervisor只支持worker Prompt；恢复校验有效版本，冲突安全拒绝。
- B：技能重写路由并扩大工具名单，引入组合和Supervisor工具执行。
- C：只注入Prompt或显示技能名，忽略绑定与恢复。

用户批准选择A。B跨到后续任务且改变授权边界；C不满足交付。

## 决定

1. Service负责当前授权/版本复核，在每次技能注入与每次新工具执行前提供离散关口回调，包含结构化计划直接执行；Agent只消费可校验快照/调用回调，不访问数据库。匹配/注入/绑定/执行状态分开，安全元数据保留来源和有效版本，不记录正文或敏感参数。
2. Prompt进入默认及fast既有路径，Supervisor只进入research/draft，不给控制节点增加技能指令。私有/全局围栏保持。
3. 工具绑定为需要集合，不能授权。默认行动、短路、fast工具路径均与原名单取交集；结构化计划验证和执行也强制该约束。ToolExecutor保留最终权限、预算、超时、有限重试与审计。空交集和缺失绑定显式说明，不退回全部工具。
4. fast SIMPLE/RAG与Supervisor暂不执行工具模式绑定；明确报告不支持，不扩大到知识库/工具组合或Supervisor执行。
5. state_json增加明确空或非空的技能版本/来源及工具约束绑定；恢复必须与当前授权一致。旧checkpoint缺绑定、版本/来源改变、技能撤销或主体失效均拒绝恢复，不自动重建执行。冲突拒绝异常须穿透运行时宽捕获，在新模型/工具调用前结束，不覆盖旧checkpoint、不discard为全新run。保留历史进度及副作用指纹，不新增表迁移。
6. 离散注入/执行前复核不等于持续授权轮询；不新增逐token或后台轮询、已开始动作撤回承诺，不扩大技能可见范围，不修改工具权限。

## 后果与兼容

现有工具默认政策不变；工具模式激活后可用工具可能收窄，空集合不再看似激活成功。旧活动checkpoint无法继续恢复，需要用户显式重新发起请求；不得后台自动重跑。新请求不受旧快照阻碍，原数据不删除。

## 验证

真实ChatService普通/流式、默认/fast/真实Supervisor矩阵；模型payload核对围栏与版本，工具副作用/新Session审计核对执行终态；私有隔离、撤权、版本切换、空交集、结构化计划、恢复冲突、取消及预算正式反例。最终全量pytest/Ruff/mypy及相应CI，独立审查和人工业务接受另记。

## 迁移与回滚

无数据库schema迁移。新字段校验失败、旧快照缺字段均明确拒绝恢复。回滚恢复接线与运行时字段，但关闭旧版恢复入口以防忽略新约束；历史记录保留，不重放工具。具体测试和手册随实现落盘。

架构批准不等于实现或验收通过；具体实现与验证以本卡证据为准。
