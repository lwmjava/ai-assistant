# ADR-0016：有界知识库与工具组合

日期：2026-10-19。状态：**Accepted，用户2026-10-19明确批准**。任务 V1C-005；架构批准不等于已实现能力或验收通过。

## 背景与事实

现有工具优先路由会跳过私有知识依据；默认 self 的 Plan v1 在检索前固定工具参数，其规划Prompt不含检索内容。ADR-0011 不允许动态参数引用，ADR-0013/0015 均未批准资料参数提取与组合执行。新增组合必须同时保留来源、安全、技能、取消、预算和旧恢复语义。

## 选项

A（推荐）：ChatService 在两编排分岔前装配请求内固定组合 helper，检索→来源参数→原执行器→回答。B：全局提前检索/改旧规划输入，兼容影响大。C：Plan v2 动态依赖，涉及更大状态恢复设计，超出当前边界。

## 已批准决定

1. 采用 A，仅显式当前安全用户消息的知识库+工具动作触发，两编排/同步流式共用固定流程；不另造通用Runtime、Executor或DAG。普通路径与Plan v1/旧checkpoint保持原语义。
2. 原卡未限定组合工具种类。建议首轮可执行支持矩阵为既有 L0 calculator，其余组合工具明确 unsupported、零执行，不能静默丢检索或当成普通工具完成。这是需用户明确批准的范围裁决；未批准不缩减原卡，不按calculator样例完成声称通用工具参数组合已交付。
3. 必须检索ok且实际选块非空，沿原权限、索引身份、注入剔除和Context Builder。no_hit/below_threshold/unavailable/关闭/预算不能装入完整块均停止依赖资料的计算；不以常识或联网替代私有标准。
4. 提取一次严格JSON：最多16条事实，每条引用本轮选块或当前安全用户消息的精确片段、数值和单位；完整JSON≤16KiB。代码核对来源、切片与数字，再将仅引用事实标识的加减乘除表达式转换为calculator参数。表达式≤64节点、深度≤8，拒绝自由常量、函数、属性、幂、未知字段、重复键和非有限数值。缺值/冲突/单位无法确认时澄清，不填默认值。引用正确不等于政策语义完全可判定，后者须用版本化案例和业务接受验证。
所有事实须实际参与表达式，至少一条来自本轮chunk，重复或未用事实拒绝。数字词法限普通十进制：整数≤12位、小数≤4位、绝对值≤10^9；费用/费率非负，人数/天数为正整数。单位限人民币元、人、天及元/人、元/天、元/人/天，原文须明确可识别；混币、百分率、单位换算或无单位不猜。加减同维度，乘除归约，最终维度为元。中间值有限且≤10^12，Decimal预检精度28。真实calculator保持int/float；实际工具数值与预检值分别ROUND_HALF_UP保留两位，只有一致才输出实际金额，不一致固定报失败，不把预检值冒充工具结果。上述限制是首轮明确支持边界，不能宣称任意财务规则计算。

5. 组合阶段至多一次检索、一次提取模型逻辑调用、一次逻辑计算；最终使用确定性模板，不调回答模型。原记忆/技能等模型用途另计，物理尝试仍受既有有限fallback、超时/token预算；不对错误提案重复采样。工具有限重试沿既有契约，授权回调每次attempt复核；零预算零执行。
6. Service负责新Session主体/租户/角色/token核验，Agent不访问数据库。复用现有Executor、工具契约与Skill白名单交集，事件让出后紧贴执行和每次重试前重验主体及技能。资料不能授予工具选择、权限或修改用户目标。
7. 结果以真实选块、经过校验的事实和ToolOutput分别追踪，成功回复仅由校验事实、真实工具数值和本轮资料组成确定性模板，不拼接自由模型解释；流式校验完成前不吐金额。失败不得由模型补造金额/成功。复用原事件、消息来源和审计字段，不改外部schema；敏感原文/原始参数不进审计或Trace。
8. 每个请求重新检索、验证来源/权限并真实执行；缓存不得复用执行成功。提取缓存不能证明主体/租户/技能版/选块摘要/协议版本隔离时，仅该调用局部bypass，不关全局缓存。取消与外层close传递并显式关闭内层迭代器，停止后继，不承诺撤回已发生操作。
9. 组合不伪装可恢复Plan v1；不自动恢复/重放，显式组合resume受控拒绝。旧v1恢复按原路径处理，附件不作为权限或私有资料替代，重新生成仍走既有权限和成功提交边界。
10. 默认self、RAG读域、向量库、配置、依赖、模型供应商、前端、数据库与既有普通/单工具/单RAG/Supervisor不变。不执行生产操作、真实索引重建或未批准费用，不授权Git发布。

## 后果、验证、迁移与回滚

固定阶段减少旧规划/恢复改动，但支持的表达式和工具集合有意受限；必须明确展示不支持/澄清，不把保守拒绝包装成完整业务成功。代码能核验数字和证据片段，不能普遍证明政策语义选择正确。

验证包含真实Service、检索器、Context Builder、Executor、本地calculator、隔离SQLite与合成模型的E2；覆盖成功/缺依据/故障/来源伪造/越权/恶意资料/缓存/取消/预算/附件/重新生成/旧恢复。AI编写数据不标Gold，不用Mock证明生产生成或检索质量。全量回归、静态检查、独立入口审查、最终审核、业务接受和最终CI按原治理执行。

无schema迁移；回退组合路由与装配/helper，保留旧消息、审计、索引和v1快照，不自动重放。本ADR的具体计划、允许路径、阈值及失败矩阵见 docs/plans/plan_v1c_005_20261019.md。
