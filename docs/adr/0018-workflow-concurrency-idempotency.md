# ADR-0018 工作流单进程准入与周期幂等

状态：Accepted；日期：2026-10-20。依据：用户明确批准PWFL-003方案及最小扩围。批准不代表已实现或已验收。

## 背景与事实

Engine为手动与cron共用入口，创建历史前无统一准入；调度器串行扫描，已有进程水位与历史辅助水位。ADR-0017限定单会话所有者与合作取消。

## 选项与决定

选择满容量拒绝，避免引入队列公平、等待取消与持久任务池契约。所有入口共享进程级WORKFLOW_MAX_CONCURRENCY（默认4，整数1..1000）。threading.Lock只保护标量准入状态，不持锁访问数据库或await。同Engine/租户/workflow活动期间拒绝重入；手动终态后允许新执行，不提供响应丢失后的终态请求去重。

cron以实际Engine实例、租户、workflow和aware UTC due绑定。只保留每workflow最新消费槽，旧槽拒绝；首次历史commit成功即消费，终态失败也保守保留，首次commit失败释放未消费槽。容量拒绝不消费due。删除清理标记。容量lease覆盖首次记录、Task/timer创建、取消清理、终态保存、webhook完成。保留现有串行扫描，长任务仍延迟后续扫描，不承诺并行cron吞吐。

## 后果与边界

进程内不同线程/事件循环共享容量，不共享Session/ORM或跨loop等待。实际Engine实例隔离周期与任务身份，容量为全进程共享。不实现跨进程锁、持久exactly-once、模型/Alembic变更或新依赖。API在既有鉴权后将准入冲突映射409，拒绝不新增历史。

## 迁移、验证与回滚

无需数据库迁移。配置、HTTP、Engine与_tick隔离集成覆盖失败边界，完整回归与最终CI依据项目规则。停止新准入、等待活动执行清理后撤回代码/配置；不修改真实库、不补放历史周期。详细计划见[实施计划](../plans/plan_pwfl_003_20261020.md)。
