# ADR-0020：原生结构化工具提议

状态：Accepted，2026-10-22。用户明确批准按原生结构化工具调用方案实施；批准不代表验证完成或生产发布授权。

## 背景和选项

dc134455 的 Agent official baseline 中 agent-003 返回 tool_call 开头、DSML 结尾的混合文本，两个工具指标均为0.5。既有严格 DSML 解析正确拒绝。继续强化提示不能保证格式；放宽解析会猜测调用意图，拒绝采用。采用 API 原生 tools/tool_calls，保留已有受控执行链。

## 决定

- 行动阶段通过 LLMOptions 的可选工具定义请求原生调用；None 保持普通文本契约，空列表表示行动阶段明确无工具。工具定义来自当前策略与技能交集，不能扩大注册集。
- 兼容客户端只接受单个 function 调用、非空ID/名称、严格JSON对象参数；拒绝重复键、非有限数字、多调用、混合文字、截断及未注册工具。把验证后的结构归一为内部 ToolCall 文本信封，以复用既有状态、指纹、Guard、Executor、Trace与审计；模型不再负责生成该信封。
- 原生请求收到文本协议指令时拒绝，不修补标签，不降级文本调用，不新增格式重试或模型请求。普通回答允许自然语言；普通非工具调用和旧合成测试提供商接口保持兼容。
- 实际 native tool_calls 响应不写入缓存；带 tools 的文本草稿把 schema 纳入缓存键后可复用。schema计入每跳上下文预算；取消、熔断和原有网络故障切换不变。无工具收尾不得接受原生或文本调用。
- DeepSeek /v1 使用官方原生工具接口，不自动切换 beta、不更换部署或模型。官方 strict 需 beta及不同schema约束，本轮不声称启用服务端strict；严格参数与权限验证仍在本地。来源：https://api-docs.deepseek.com/guides/tool_calls/ ，2026-10-22核对。
- 运行时与官方评测发送相同工具定义、使用相同客户端解析。报告明确工具回复是客户端归一结果，不能宣称原始HTTP信封；冻结数据和阈值不变，评测器版本更新。

## 验证、失败边界及回滚

离线HTTP替身覆盖请求/响应、原始畸形样本、参数与协议拒绝、缓存/预算/取消/故障切换；真实Pipeline/短路/Supervisor调用方专项、身份/撤销/跨租户旧fixture与相关Evaluation回归，独立审查真实入口。适用最终CI未完成不得关闭；真实付费复验与Git发布另按授权。回滚本次options、客户端和行动/评测接线及Prompt，不修改数据库或重放工具；旧报告保留，旧文本解析用于既有存量契约。
