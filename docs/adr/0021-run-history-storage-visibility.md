# ADR-0021：运行历史存储与可见性

- 状态：Accepted
- 日期：2026-10-23

## 决定

对话执行完成后把运行摘要和事件的脱敏投影写入主数据库。记录绑定 `tenant_id`、`user_id` 与 `conversation_id`；所有者可读本人记录，同租户 `tenant_admin`/`system_admin` 可读租户记录，拒绝与不存在统一返回 404。

默认查询保留窗为 30 天。过期只从查询中隐藏，不自动物理删除；删除已落记录需另行授权。事件只保存类型、节点/工具/模型名、相对时间、耗时、工具状态与轮次，不保存 Prompt、回答、工具参数、结果、凭据或原始错误。事件最多 200 条。Token 用量仅在存在可信来源时记录，否则保持 `null`，不得填 0。

历史读取是纯查询，不重放模型、工具或工作流。内存 Trace 继续用于当前进程调试，但不作为持久证据。

## 已批准的平台准入更新与计数口径

2026-10-24 已批准的[真实资源设计](../superpowers/specs/2026-10-24-real-resource-evaluation-design.md)将运行历史页面/API准入统一收口为 `system_admin`，取代上文对公开读取入口的所有者/租户管理员准入描述。Service 内的同租户、所有者/管理员资源过滤仍保留，不因此扩大跨租户读取权限；其他角色在API入口返回403，已准入管理员对不可见/不存在记录统一404。

调用次数及耗时独立于详细事件开关累计。模型计数是已接入执行入口的模型调用尝试（含失败、取消和流式关闭）；工具计数是通过管线本层守卫后交给受控Executor的一次逻辑调用（含Executor拒绝、失败、取消），不等于工具底层重试次数或计费次数。跳过、无效意图、预算耗尽等决策只保留可选调试事件，不增加调用数。关闭debug不保存Prompt、回答、工具参数/结果等详细载荷，持久层继续白名单投影；Token缺可信usage时保持null。

本次不推断或覆盖旧记录的0计数；旧记录缺少原始证据，不能凭修复反推历史用量。完整入口覆盖和最终版本验证以当前任务记录为准，不能仅凭摘要计数宣称供应商计费闭环。

## 回滚

可关闭写入并移除查询路由和页面；保留已写记录。包含数据的表不得由 downgrade 隐式删除。
