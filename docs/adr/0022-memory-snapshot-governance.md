# ADR-0022：会话记忆快照治理

- 状态：Accepted
- 日期：2026-10-23

## 决定

记忆快照只服务单个会话，不提供跨会话抽取、检索或画像。读写必须绑定当前有效用户、租户、会话归属和现有 Chat 授权；跨租户、已删除会话、停用用户/租户或撤销版本变化时拒绝旧快照。

快照绑定策略版本、压缩版本、用户撤销版本、已处理消息数与已处理前缀摘要。消息编辑/删除、游标越界、版本漂移或摘要损坏时不使用旧摘要，回退到受权原消息安全重算。默认有效期 30 天；过期只失效，不自动物理删除。会话软删除显式标记快照失效，物理删除另需授权。

只持久化经过输出清理的摘要和验证元数据，不保存另一份原始消息。跨会话长期记忆仍为 Deferred。

## 回滚

关闭快照读写并恢复现有全量会话压缩；保留已落快照。包含数据的迁移不得隐式降级删除。
