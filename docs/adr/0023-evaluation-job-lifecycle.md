# ADR-0023 受预算评测任务生命周期

状态：Accepted；日期：2026-10-23，2026-10-24补记。初始保守方案不包含真实付费模型或数据外发；后续真实 RAG 质量验证的有限授权见末节。未批准生产操作或发布。

## 背景

现有检索、生成和 Agent 评测 runner 只能由命令行同步启动。评测数据集与报告已有受权读取入口，但没有统一任务状态、取消、并发、幂等和重启处理，页面不能安全启动长任务。

## 决定

新增租户隔离的 EvaluationJob，由 EvaluationJobService 作为唯一状态机入口。任务绑定提交人、租户、数据集及不可变版本、runner、运行模式、输入哈希、预算、幂等键和报告结果。状态为 queued、running、cancel_requested、succeeded、failed、cancelled、interrupted；终态不可逆。相同主体和幂等键仅在请求指纹一致时返回原任务，不一致时冲突。

runner 通过固定注册表调用，参数由服务端构造，不接受命令、脚本路径或任意参数。进程级并发默认 1、可配置为 1..8；单任务总时限默认 900 秒。取消为合作式取消：先记录 cancel_requested，再终止已登记的任务；在启动前取消直接进入 cancelled。启动恢复把遗留 queued/running/cancel_requested 收敛到 interrupted，不自动重试。

排队只持久化在数据库。调度通知和任务释放槽位时，在同一进程锁内按 created_at/id 领取最多空闲槽位数的 queued 任务；内存取消标记及已提交执行项均受并发上限约束。排队取消不占用执行槽位，停机后不继续领取。若 worker 出现未被任务状态机收敛的意外异常，当前调度器停止领取并通知活动任务取消，仅记录异常类型；保留非终态任务供进程重启恢复，不自动重试，也不累计失败 ID 集合。

本批真实外部模型调用预算固定为零。只允许 retrieval/smoke、generation/synthetic、agent/smoke 三种零费用模式；official/real 请求在创建任务前拒绝且不生成任务记录。测试 runner 只能证明生命周期，不能作为质量或上线证据。

## 权限、数据与错误

创建和取消沿用 evaluations:write；读取沿用 evaluations:read。非 system_admin 只能操作本租户任务，取消还要求提交者本人或 tenant_admin；越权与不存在统一返回 404。任务只保存允许字段、报告相对路径与哈希，不保存密钥、完整 stdout/stderr 或任意外部 payload。runner 非零退出、超时、取消和报告校验失败均保留确定终态及脱敏错误码，不隐式重试。

## 迁移、验证与回滚

新增 evaluation_jobs 表和向前迁移；不改已有评测数据与冻结报告。验证覆盖幂等冲突、租户隔离、预算拒绝、并发、取消、超时、失败、重启收敛、报告绑定和旧接口回归。回滚时停止新任务并受控结束活动任务，关闭新入口，保留任务与报告证据，不自动删表或清理数据。

## 2026-10-24 真实生成与 Judge 授权补记

用户批准 RAG 生成与 Judge 复用当前国内 OpenAI-compatible 服务，首次验证限合成或确认脱敏数据、10 条用例、30 次请求、5 元；价格无法可靠核算时只完成接线。此补记取代上文“外部预算固定为零”对新真实资源 RAG 质量任务的限制；旧内部 Smoke 仍零费用。真实资源产品入口使用 system_admin 准入，与内部旧 runner 权限描述区分。

采用评测专用计费会话，复用兼容客户端与模型上下文护栏，不改变公共 LLMProvider 返回协议。前置确认数据外发，冻结当前完整端点/模型、最高价格/依据、能力与 Prompt 版本；逐请求预占并持久化调用数，成功按 usage 结算，失败/取消/未知 usage 保留预占，不隐式重试。运行时复核管理员撤销版本、目标租户/文档/索引和数据集哈希；总超时覆盖真实资源 runner。生成内容仅在内存交给 Judge，落盘哈希、合法引用 ID、分数、usage 及费用。Judge 使用严格版本化 JSON，无参考答案时正确性缺测；同模型评分仅辅助，不新增发布阈值。关闭质量配置即可回滚入口，保留证据，无新增表或迁移。

检索阶段 Embedding 请求纳入同一计费会话与费用/请求硬上限，独立登记当前 Embedding 价格、端点/模型/维度；未知时拒绝整个质量任务。专用 Embedding 适配器只用于评测，保留现有活动索引与输入策略且不重试，不改变公共检索行为。
