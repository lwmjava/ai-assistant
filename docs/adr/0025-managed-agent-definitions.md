# ADR-0025 受控 Agent 定义与执行权限

状态：Accepted

Agent 定义采用私有、租户和系统三种作用域。私有定义由所有者管理，租户定义由本租户管理员管理，系统定义由系统管理员管理。读取按当前身份及作用域判断，租户定义拒绝跨租户读取。创建、发布、回滚和启停记录审计，与状态变更在同一事务提交。

版本内容发布后不可变。定义通过生效版本指针发布或回滚，停用后拒绝新执行。执行开始时解析并固定具体版本，历史版本保留供审计。管理请求使用期望版本校验并发冲突。

复用现有 ChatService、Pipeline、Supervisor 和 Tool Executor。定义仅引用已登记工具，运行时工具权限取定义白名单与当前主体授权的交集。未知工具及越权请求拒绝，执行时继续执行原工具权限与审批校验。用户输入和模型输出不得改变定义作用域或工具授权。

回退时停用动态定义入口并恢复内置定义，保留持久化版本及审计记录。
