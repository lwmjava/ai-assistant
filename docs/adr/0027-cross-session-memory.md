# ADR-0027：跨会话记忆的存储、注入与关闭

- 状态：Accepted
- 日期：2026-11-08

## 决定

跨会话记忆沿用当前配置的向量库保存向量，并在主库另存可追溯元数据。元数据至少包含租户、用户、来源会话、来源消息、嵌入身份、策略版本和到期时间。向量不写入知识库文档分块。

默认关闭。只有调用方明确保存一条已有消息时才写入，不保存全部对话。后续对话在现有记忆上下文之后注入检索结果。检索仍校验当前用户、租户、令牌版本、来源会话未删除和到期时间。

Milvus 是当前向量库时，检索失败不改用本地向量排名。关闭开关只停止读写，不删除已写入的记录。

## 回滚

把跨会话开关设为关闭。已写入的元数据和向量保留。含数据的迁移拒绝直接删表。
