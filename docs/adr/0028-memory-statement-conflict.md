# ADR-0028：长期记忆的来源分级、去重、冲突与纠正

- 状态：Accepted
- 日期：2026-11-08

## 决定

长期记忆只在调用方明确保存一条已有消息时写入。用户消息记为用户陈述，助手消息记为模型推断，系统消息拒绝写入。模型推断不能改写成用户陈述，也不能覆盖已有用户陈述。

相同主体、来源等级和规范化正文的有效记录只保留一条。同一主题的两条不同用户陈述都保留，并标成同一冲突组。纠正新增一条版本并指向旧记录；旧记录留在库里，当前检索不再返回它。

正文含手机号、证件号、银行卡号、邮箱、IP 或密钥时拒绝写入，不改存脱敏后的文本。关闭跨会话开关仍只停止读写，不删除这些版本。

## 回滚

关闭跨会话开关。已写入的陈述、推断、冲突组和纠正版本都保留。含数据时拒绝删除这些列。
