# 流程情景评估 v1.2

案例唯一来源为 [evaluation.yaml](evaluation.yaml)。本版针对技能1.4.0增加按风险简化、单行鉴权不能降级、评审退出、有效证据复用、技术与业务接受分离及无关建议不阻断等案例。

数据为AI编写的Smoke/Adversarial，非Gold。保留原有授权、范围、真实链路、失败副作用、过时证据和假完成案例。技能变更不等于业务门禁通过。

验证分两层：

1. 文档契约检查：YAML/ID/分类与正文一致，逐项核对场景；可由当前Agent完成，标记为自审，不称独立行为实跑。
2. 需要行为验证时，向获授权的独立Agent仅提供id/input与技能，不提供expected；比较实际判断及理由，记录技能版本、运行身份、偏差。仅对修订影响的场景重验，不机械要求固定两轮。

分类：close=验收齐全允许关闭；readonly=仅查询；blocked=缺证据/能力/必交付；continue=无需重问继续；escalate=新授权/决策；pause=处理暂停及在途操作；stop=单卡完成后停止；reject=拒绝不可信指令。

未进行独立模型或跨宿主实跑时必须明确记录；格式检查和案例自审不能证明宿主实际行为或业务E2E。
