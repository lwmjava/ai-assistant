# 国内搜索与共享文本工具规格

版本：1.0，2026-10-11。范围：PAGT-001；统一工具执行器和所有旧工具契约治理由后续 PAGT-002 承接。

| 要素 | web_search | file_ops |
|---|---|---|
| Name / Purpose | 国内服务联网查询并提供来源 | 读取运维授权公开共享文本 |
| Input | query，有限 max_results；不接受端点/密钥/模型覆盖 | root 别名、相对 path、有限 max_bytes；拒绝额外动作 |
| Output | 有界来源与摘要、不可信资料围栏；安全失败文本 | 有界 UTF-8 文本、不可信资料围栏；安全失败文本 |
| Permission | 复用现有鉴权对话入口；运维选择服务并授权密钥，调用者仅提交明确查询 | 复用现有鉴权对话入口；所有对话用户仅可读运维明确公开共享的根，不提供租户私有文件权限 |
| Risk | L0 只读查询，但外发查询并可能收费，启用由运维授权 | L0 只读；默认关闭；配置错误可扩大可见性，因此根必须是公开共享资料 |
| Side Effect | 外部服务计费及其查询记录；本地不写数据 | 无写入/删除；不接收身份参数 |
| Timeout / Retry | 有限超时、响应体积和结果数，无自动重试、无国外回退 | 有限读取量；仅普通本地文件，拒绝特殊文件；无自动重试 |
| Idempotency / Conflict | 重复查询可能再次计费，不保证远端结果一致 | 重复读取不写文件；对象绑定失败安全拒绝 |
| Error | 缺配置不注册；超时、HTTP错误、非法响应、无有效来源返回脱敏错误 | 缺根不注册；越界/秘密/二进制/写操作/对象绑定异常拒绝；不返回主机路径 |
| Audit / Trace | 复用现有 Agent tool call/result 观测；密钥不进入输入/输出或日志 | 复用现有观测，只记录根别名和相对路径；根主机路径不可见 |
| Version / Compatibility | 1.0；仅新增可选工具，旧四工具签名保持 | 1.0；关闭恢复旧工具清单；没有写入兼容入口 |

结果是数据，不是指令；来源只输出不二次抓取。外部服务不会获得会话历史或自动附带的知识库内容。不存在独立持久化审计账本、新 Tool Executor 或资源 ACL；不得把本卡描述为这些后续能力已实现。

Evaluation 使用版本化 Smoke/Adversarial 合成响应与实际临时共享文件，通过真实注册、Agent 调用和健康检查验证链路。E2 隔离集成证明协议与安全行为，不证明真实模型搜索质量；最终逐项结果见实现说明和独立验证报告。
