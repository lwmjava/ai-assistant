# ai-assistant 评审与发布检查清单

> 开发审查按AGENTS.md第9节风险分级及任务影响选用；发布时核对适用生产项。已触发的门禁不能裁剪。清单可放进同一交付记录，不强制单独报告。

## 1. 需求和任务

- [ ] 关联当前任务及确有适用要求的Product Spec/设计/ADR，未要求为常规修复新建规格。
- [ ] 验收标准可执行。
- [ ] Non-goals 明确且未被实现。
- [ ] 业务、技术、安全和发布责任人明确。

## 2. 代码评审

- [ ] Diff 范围与任务一致。
- [ ] 公开 API/Event/Schema/错误码兼容。
- [ ] API、Service、Agent、Tool、RAG、MCP 分层合理。
- [ ] 无 Agent/Prompt/Skill/MCP 直连数据库。
- [ ] 无未批准依赖、架构或供应商变化。
- [ ] 无未解释的临时绕过和硬编码。

## 3. 权限和安全

- [ ] 身份、租户、角色、资源和动作权限均验证。
- [ ] 跨租户和 IDOR 测试通过。
- [ ] RAG/Tool/MCP/网页内容按不可信数据处理。
- [ ] L2/L3 策略和人工审批不可绕过。
- [ ] 密钥、PII、连接串和堆栈未泄露。
- [ ] 日志、Trace、审计和 Evaluation 数据已脱敏。

## 4. RAG

- [ ] 正式 VectorStore 摄取、检索、更新和删除一致。
- [ ] Embedding 模型、维度和索引版本兼容。
- [ ] 文档版本、生效时间和权限过滤正确。
- [ ] Citation 可回指 document/chunk/version/page/section。
- [ ] RAG baseline 和候选使用同一数据集。
- [ ] Recall、Ranking、Citation、正确性、幻觉和安全达到已批准门槛。

## 5. Agent、Skill、Tool、Workflow

- [ ] Tool Schema、权限、风险、超时、错误、审计和版本完整。
- [ ] 副作用 Tool 具备幂等、冲突和补偿。
- [ ] Skill Preconditions、Workflow、Constraints、Escalation 完整。
- [ ] Agent 步骤、Tool轮次、时间和成本受限。
- [ ] Workflow 状态、重试、取消、失败和恢复可验证。
- [ ] 最终业务状态正确。

## 6. 验证命令

按影响运行并记录；`AGENTS.md` 第 10 节触发的强制检查不得以专项测试替代。开发阶段记录专项与调用方；完整 pytest 可引用最终 SHA 合格 CI，验证基础设施首次变更仍须本地全量：

```powershell
pytest
ruff check .
mypy app/
cd frontend
npm ci
npm run typecheck
npm test
npm run lint
npm run build
```

- [ ] 实际命令、退出码和报告已保存。
- [ ] 未运行项有原因、风险、Owner 和截止日期。
- [ ] Mock 测试没有替代必要的真实集成。
- [ ] 失败案例已沉淀，未删除或弱化。
- [ ] 开发前基线 SHA、已有改动及既有失败已记录；新增失败已归因。
- [ ] 公共入口/执行链/模型调用/缓存/全局配置变化已在开发阶段覆盖调用方专项；完整 pytest 已由最终 SHA 合格 CI 承担，或按第10节完成本地全量。未用筛选或关闭相关功能替代。
- [ ] 独立审查发生在专项通过后、最终全量前；起始材料未整份发送台账/manifest；配额耗尽未写成无发现。
- [ ] 新增身份复核的旧成功 fixture 有有效 User/Tenant；撤销、停用和越权拒绝仍有断言。
- [ ] 新增模型请求按用途统计，缓存/预算/取消/重试断言仍验证原业务结果。
- [ ] 平台相关变化的 Linux 测试及同一最终提交 Ubuntu Backend CI 已通过；Windows 不作替代。
- [ ] 报告与最终源码/测试/配置/依赖/评测输入指纹或提交 SHA 一致，相关输入变化后已重跑。
- [ ] 必要检查失败/缺失/过期时业务卡未标 done；WIP 保存未被写成验收通过。
- [ ] 合并前核验最终 SHA 的 Backend、Frontend、Agent official baseline 必需检查及分支保护/bypass 策略；未核验项未写成自动保护已生效。

## 7. Evaluation

- [ ] 数据集、评分器和阈值有版本。
- [ ] Gold 有人工确认。
- [ ] 关键权限、安全和高风险切片为阻断门禁。
- [ ] 模型非确定性有重复运行或方差说明。
- [ ] 报告包含失败 Case 和残余风险。

## 8. 可观测性

- [ ] request/task/trace/step 可关联。
- [ ] 能区分模型、RAG、Tool、权限、数据和外部依赖失败。

- [ ] 制品、代码、配置、Prompt、模型和索引版本固定。
- [ ] Feature Flag、灰度租户/流量和观察窗口明确。
- [ ] 自动/人工停止阈值明确。
- [ ] 应用、配置、数据库、模型和索引回滚已验证。
- [ ] 回滚不会重复副作用或破坏数据。
- [ ] 生产写入和高风险操作已取得授权。

## 10. 评审退出与业务接受

- [ ] 适用的独立审查已真实完成；普通任务未机械增加第二轮最终审核。
- [ ] 范围内阻断问题已闭合；无新相关输入/失败/证据时结束本轮，无关建议另记。
- [ ] 技术验证、独立审查与业务接受分别记录；AI验证未称人工审核，受托操作验收有明确授权与实际场景。
