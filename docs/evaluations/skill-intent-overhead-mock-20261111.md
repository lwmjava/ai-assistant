# 技能匹配与意图分流开销：Mock 对照记录

记录时间：2026-11-11 23:19（Asia/Shanghai）。评测版本：skill-intent-overhead-0.1.0。来源：Mock，只证明测量和档位选择接线，不能当作真实质量或费用结论。

## 做了什么

- 请求级追踪摘要始终记录技能匹配、路由、意图分流、检索、工具和回答阶段耗时，以及模型用途、调用次数、首个可见/模型 token 时延和测评版本。详细事件仍仅在调试模式写入，不保存 Prompt。
- 单变量实验：仅在开关打开时，已判定为简单路径的回答生成改用已配置的意图档模型；工具、知识库、多轮和组合路径仍用对话档。不按意图置信度或问题长度估计难度。
- 生产默认开关保持关闭，未改官方 RAG 门槛、holdout 或冻结报告。

## Mock 结果

对照（开关关闭）4 条：路由/技能/工具正确率均为 1.00 / 1.00 / 1.00。
处理（开关打开）同样 4 条，正确率不变；简单路径生成任务为 intent，其余为 chat。

决策：not_a_real_baseline。mock results cannot be used to adopt or reject the experiment。真实模型基线未跑，因为没有费用授权；这不等于实验不采纳，只是尚未准入。

取消、缓存、预算和权威检查相关回归在本机专项中保持通过；未跑真实模型，也未改生产默认。
