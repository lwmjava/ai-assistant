# 技能匹配与意图分流开销：真实模型对照

记录时间：2026-11-14（Asia/Shanghai）。评测版本：skill-intent-overhead-0.1.0。来源：真实模型。生产开关 `LLM_MODEL_TIER_ROUTING_ENABLED` 在测量前后都是关闭，这次没有把它写入配置。

## 单变量

基线关闭档位开关，四例回答都请求对话用途。处理组打开开关：只有已判定为简单路径的用例改请求意图用途，工具、知识库和组合路径仍请求对话用途。路由、技能和工具对错沿用该评测版本的现有记分，不另改门槛。

当前环境没有单独的意图档密钥或模型名。意图用途因此解析到对话模型 `deepseek-flash`。八次调用观察到的模型都是这一个。

每次调用都关闭了响应缓存，温度 0，输出上限 512 token。知识库检索和工具执行没有跑，避免把索引或计算器耗时混进模型对照。本地路由记分低于 0.1 ms，不能当成检索或工具性能。

## 结果

| 用例 | 基线用途 | 基线首 token | 处理用途 | 处理首 token | 路由/技能/工具 |
| --- | --- | ---: | --- | ---: | --- |
| simple-greeting | chat | 1164.6 ms | intent | 936.6 ms | 正确 |
| calculator-tool | chat | 645.5 ms | chat | 1096.4 ms | 正确 |
| knowledge-lookup | chat | 1402.7 ms | chat | 1532.0 ms | 正确 |
| combined-policy | chat | 1861.5 ms | chat | 1562.2 ms | 正确 |

四例路由、技能、工具正确率均为 1.00。基线首 token 平均 1268.6 ms、P95 1861.5 ms；处理组平均 1281.8 ms、P95 1562.2 ms。每例只计 1 次模型调用。

机械对照看到 P95 下降超过 15%，会给出 `adopt_candidate`。平均首 token 没有下降，而且处理组并没有换模型，所以这次 P95 差异不能算档位收益。

## 决定

`not_adopted`。意图档位开关保持关闭，不合并到默认回答路径。Mock 对照仍只证明接线，不能用来采纳或否定实验；本记录与 `docs/evaluations/skill-intent-overhead-mock-20261111.md` 分开。
