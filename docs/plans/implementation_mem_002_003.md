# MEM-003 / MEM-002 实施说明

两卡共用 ADR-0022 和唯一策略接口。MEM-003 在 Chat 真实入口验证当前身份、撤销版本、租户状态和会话归属；MEM-002 只在通过该策略后读写单会话摘要快照。

快照保存经过清理的摘要、压缩消息数、消息前缀哈希、策略/压缩器版本、主体与30天有效期。后续请求只把游标后的消息交给 `MemoryManager`，因此旧消息不重复压缩，`keep_recent` 仍保留原文。编辑/删除、游标/哈希、撤权、停用、过期或版本变化会拒绝旧快照并从受权消息安全重算；压缩失败不推进游标。

不实现跨会话记忆、向量检索、画像、自动物理删除或现有数据迁移。回滚关闭快照读写并恢复全量会话压缩，保留已落快照；有数据时迁移 downgrade 拒绝删表。
