# 单卡自动交付技能创建说明

后续修订：本文件记录初始v1.0创建；v1.1缺陷修复及两轮核验见[修复实现说明](implementation_task_card_delivery_skill_fix_20261006.md)。不以初始结构校验代表后续行为评估。

## 目标与方案

用户要求将已讨论的多 Agent、技能链、自动验收交付提示词生成可供 WorkBuddy 或豆包读取的技能。新增仓库内可移植 SKILL.md 和流程情景，不修改业务代码、任务卡或项目全局规则，不安装至其他工具。

## 实际交付

文件：docs/ai-prompts/skills/task-card-delivery/SKILL.md、同目录 evaluation.md 及本文。

技能包含计划审查、失败案例、实施、根因调查、独立审查、浏览器 QA、修复闭环、文档与证据交付。采用宿主工具能力检测及等价流程，避免要求其他工具必须安装 Codex 的命名技能。

自动验收替代人工操作以用户当前明确授权为条件；保留范围、生产及重要数据授权限制。缺子 Agent、浏览器或仓库能力时不伪称独立审查、页面通过或任务完成。不会自动推进下一张卡。

## 使用与边界

在可访问仓库的工具中提供 SKILL.md 相对路径并明确目标卡；无法访问仓库时可提供该文件和必要项目上下文，但普通聊天不能执行代码验收。未验证 WorkBuddy 或豆包的原生技能发现、安装目录及多 Agent 支持；不宣称已安装或能自动加载。

本次是用户明确授权的开发协作技能文档交付，不新建业务任务卡、不改变既有卡状态，不提交、推送或部署。验证结果见本次补记。

- 未执行业务测试、浏览器验收或跨工具实跑，因为本次仅新增协作技能文档。未证明 WorkBuddy/豆包原生发现和加载。
