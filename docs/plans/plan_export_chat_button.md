# 对话页导出本租户对话

> 状态：已实现。说明见 `docs/plans/implementation_export_chat_button.md`。导出接口见 `docs/plans/implementation_export_001.md`。
> 来源：导出接口已上线后，需要在对话页点选测试。不新开任务卡。

## 目标

当前租户的租户管理员在对话页点击「导出本租户对话」后，浏览器下载 `conversations.json`。系统管理员点同一按钮时，页面说明无权导出，不开始下载。内容过大或审计未写入时，页面说明没有开始下载。

## 现状

`POST /api/export/conversations` 已按成员关系上的 `tenant_admin` 放行，成功时先写审计再返回附件。对话页没有调用这个接口。审计页筛选里没有 `export_requested` 的中文名。

## 方案

对话页顶栏对 `tenant_admin` 和 `system_admin` 显示按钮。请求带当前访问令牌，空正文。成功则触发本地下载，文件名 `conversations.json`。403、413、503 用页面上的说明展示，不把对话正文写入提示。审计筛选项增加「导出对话」。不改导出 JSON、条数上限、字节上限和审计先于正文的顺序。

## 非目标

不按单条会话筛选。不改训练格式。不在知识库页放导出。不把系统管理员做成可以下载。

## 验收

租户管理员点击后浏览器开始下载，文件是本租户对话 JSON。系统管理员点击后看到无权导出，没有下载。413 与 503 的文案说明没有开始下载。
