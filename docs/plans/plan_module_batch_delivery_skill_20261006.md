# 模块多任务自动交付技能实施计划

目标：按用户明确要求创建可供不同 Coding Agent 读取的模块批次技能，一次授权任务集合，按依赖连续完成单卡开发、审查、验收、评估与模块交付。

现状：已有单卡技能，但批次授权、依赖阻塞、最终模块回归和防假完成约束不足。RAG-022 曾在参数重放未实现时标为 done，必须作为回归情景。不同宿主的子 Agent 与浏览器能力未验证。

方案：在 docs/ai-prompts/skills/module-batch-delivery/ 创建自包含 SKILL.md 与必要验收参考、情景数据。沿用每次一张卡的项目规则，自动串行推进已授权集合，同卡内多 Agent 分工。以原始任务契约对账、有效证据和模块回归决定关闭；不修改项目全局规则。

非目标：不实施任何业务任务，不修改 tasks.yaml、不安装其他宿主插件、不声称支持跨工具自动发现、不授权生产、索引重建、模型费用或 Git 发布。

验收：格式校验；独立 Agent 使用真实或合成原始材料进行正向与反向决策评估；独立最终审查；实际命令与评估边界写入实现说明。测试不能执行生产写入或真实模型调用。审查结论存 docs/reviews/。

授权：用户当前明确授权创建和核验多卡技能；未来每次使用需明确目标模块或卡清单。批次授权不等于全仓 backlog 授权。
