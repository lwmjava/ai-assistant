## 方案与取舍

采用现有 httpx + provider 适配模块：默认 DashScope 原生 Generation API 的国内端点和 qwen-plus；另提供智谱国内端点及官方 web-search-pro 搜索模型、博查自有 Web Search API、百度千帆 AI Search 国内模型。仅接受明确国内 provider/模型集合，固定请求域名，不支持国外提供商或国外兜底、不允许调用者提交模型/端点/key。DashScope 强制搜索并返回搜索来源；智谱返回 search_result，博查/百度分别解析官方搜索网页列表/引用。搜索结果统一为 provider/model、标题、URL、受限摘要和状态，标记不可信；不自动访问来源网址，不把生成内容冒充已核实网页事实。缺 key、关闭、非法配置不注册进 Agent，健康检查仅返回脱敏状态，不发收费探测请求，不改变数据库/vector故障的既有HTTP状态。

原 PRD 枚举的是国内默认+三种国外服务，当前用户约束下用四个国内适配器保留可插拔数量，同时替换原国外清单。博查为搜索 API，不额外请求国外生成模型；其响应协议相似不代表调用 Bing。对应产品段落同步说明本次用户决定。未指定收费调用授权，不读实际 .env/key，不调用真实远端做验收。

file_ops 默认关闭，配置为管理员维护的明确**共享公开资料根**别名→路径JSON映射；工具仅接收根别名、相对文件路径和有限读取上限，不接受主机绝对路径或身份参数。不把它作为租户私有文件管理接口，不允许租户上传目录、数据库、生产配置目录进入共享根。所有获准发起对话的主体可以读取这些被运维明确授权共享的资料，未配置根拒绝注册；越界、绝对/驱动器路径、..、符号链接/junction越界、秘密文件、目录/特殊文件、二进制均拒绝。只读文本，固定有限字节/字符，最终规范化路径校验与打开对象绑定，避免仅检查后任意路径打开；不提供写/删除/列目录。健康检查不暴露根路径。

取舍：相比把联网参数塞进主LLM工厂，本方案不改变主对话供应商与既有模型护栏；相比全工具契约重构，本卡只为新增能力补规格、限制和现有Trace覆盖，统一治理由 PAGT-002 承接。brainstorming 用于这两种方案的边界比较；按显式调用技能连续执行常规范围内工作，不重复确认。

## 失败边界清单（每类补正式反例）

1. 数值：结果数/字节数/超时拒绝 bool、NaN/Infinity、负数和极端幅值；输出/响应大小有硬上限。
2. 失败：HTTP超时/429/5xx/非法JSON/空结果/缺来源，安全错误不包含堆栈或密钥；取消传播，不无限重试，不默认回退国外。
3. 权限/租户：默认关闭/无授权共享根拒绝；跨共享根、tenant数据目录、.env/.git/DB、绝对/..路径拒绝；不接受伪造身份参数，无跨请求缓存。
4. 身份绑定：未知或国外provider/model拒绝，不允许改变端点；文件相对根绑定、符号链接/junction逃逸、TOCTOU与特殊文件防护；key/主机路径不出现在health或失败结果。
5. 回滚/幂等：关闭新开关后只保留旧四工具；故障后旧工具继续可用；重复读取不写文件，失败不更改数据；历史Prompt登记保留。

先有效失败测试，再最小实现，再适用pytest+全仓Ruff+完整后端mypy；Evaluation落docs，不越界改evals目录。没有前端变更则页面不适用，不凭代码声称真实页面验收。API健康契约同步README/OpenAPI说明及契约测试。前置与最终源指纹写实现说明。独立审查未决P1/P2不得关闭；人工业务验收仍需本卡用户明确认可。

## 风险与回滚

web_search发送调用者显式查询到国内服务并可能收费，当前只用隔离模拟服务验收；上线开关/密钥由运维授权配置，查询不额外携带历史/租户文档。file_ops读范围是运维显式公开共享目录，不兼作租户私有目录，默认关闭。通过关闭工具配置回退到旧四工具，恢复源码发行和对应Prompt登记。当前用户仅授权新分支与本卡实施，未授权本卡提交推送、生产开启或实际收费探测。
