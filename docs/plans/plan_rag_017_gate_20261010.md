## 3. 门禁规则（阈值建议，需批准）

**3.1 配置一致性（防「改配置跑高分假通过」）**：报告 `run_config` 必须与冻结基线一致——`embedding_provider` 非 Mock、`embedding_model=text-embedding-v3`、`embedding_dim=1024`、`rag_backend=native`、`chunk_strategy=structured`、`chunk_size=500`、`chunk_overlap=64`、`rrf_k=60`、`vector_store=local`。任一不一致即失败。

**3.2 指标门槛（建议档，基于实测稳定水平留约 1 例余量）**：

| 指标 | 建议门槛 | 依据（历史最低/实测） | 严格档 | 宽松档 |
|---|---|---|---|---|
| Recall@1 | ≥ 0.78 | 实测 0.810 稳定、冻结 0.795 | ≥ 0.80 | ≥ 0.76 |
| Recall@5 | ≥ 0.94 | 实测 0.962（连续两次） | ≥ 0.96 | ≥ 0.92 |
| Recall@10 | ≥ 0.94 | 实测 0.962（连续两次） | ≥ 0.96 | ≥ 0.92 |
| MRR | ≥ 0.92 | 实测 0.943、冻结 0.929 | ≥ 0.94 | ≥ 0.90 |
| nDCG@10 | ≥ 0.92 | 实测 0.940、冻结 0.942 | ≥ 0.94 | ≥ 0.90 |
| 安全切片越权 | == 0 | 2026-10-04/10 均已为 0 | 0（无严格/宽松） | — |

- 说明：语料小（13 篇 / 37 块 / 44 案例），单例权重约 0.024，门槛取「实测稳定值 − 约 1 例余量」，避免正常波动误伤；任何指标跌破即整体失败。
- 默认按**建议档**实施；批准时可指定严格档/宽松档或自定义数值。

**3.3 外部模型失败**：评测脚本本身在嵌入调用异常时退出非 0，门禁步骤随之失败；gate_check 对缺失/损坏报告同样返回失败——**外部模型失败不得记质量通过**。

**3.4 门禁走实际对话过滤契约**：评测 harness 复用生产 `RAGService`，检索按 `tenant_id` 过滤（如实反映配置，评测侧不补造 ACL），安全切片用案例的 `forbidden_document_ids` 判定。

## 4. CI 集成

backend job 追加（ubuntu，复用已装依赖，`EMBEDDING_API_KEY` 从 GitHub Secrets 读取）：

```yaml
- name: RAG baseline gate
  env:
    RAG_BACKEND: native
    RAG_CHUNK_STRATEGY: structured
    RAG_VECTOR_STORE: local
    RAG_EFFECTIVE_DATE_FILTER: 'false'
    EMBEDDING_API_KEY: ${{ secrets.EMBEDDING_API_KEY }}
  run: |
    python scripts/run_rag_baseline.py --mode official --out evals/reports/rag-v0.1-baseline-ci.json
    python scripts/rag_gate_check.py --report evals/reports/rag-v0.1-baseline-ci.json --baseline evals/reports/rag-v0.1-baseline-20260919.json
```
