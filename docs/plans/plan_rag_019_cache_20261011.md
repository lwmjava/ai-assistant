依据：tasks.yaml 原始 RAG-019 契约；已批准的 ADR-0008 缓存身份约束和 2026-10-06 剩余任务顺序。分支 codex/rag-019-cache，基线 HEAD 7709d7b。用户 2026-10-11 额外授权 README.md，仅补充缓存配置、限制、回滚。

## 目标、现状与方案

当前每次检索和生成均调用后端。增加默认关闭、有 TTL、LRU、条数及总字节限制的进程内缓存，保持 Service、Backend 和 Provider 边界；不引入 Redis、依赖或新的顶层架构。

检索缓存置于 RAGService 使用的 Backend 装饰器，覆盖 search 与对话 Retriever。键绑定数据库、真实实现、参数、主体/授权域、完整文档/分块/索引内容指纹与当前日期可见状态。命中前重新检查索引身份和 SQL 授权；失败不得释放原缓存。写期间变化不缓存，脏事务不缓存。缓存返回独立副本。

LLM 缓存置于实际 OpenAI 兼容 Provider 单跳，不缓存 FallbackChain 最终结果。仅显式开启、认证请求作用域存在、有效 temperature=0、合法数值参数且完整文本 stop 响应、实际响应模型与请求模型一致时可存储。键包含实际 messages（包括上下文）、全部请求选项、端点、凭据摘要、模型、代码/Prompt 版本、配置和最新数据/授权指纹。chat 和 stream 分键，stream 完整结束且收到 DONE 才写缓存；命中每次输出再授权。预算与输出安全仍执行。请求关闭后作用域失效，后台反思不得沿用租约。

## 非目标与兼容

不引入 Redis；不缓存 temperature>0、未知主体、无实际身份的模型响应、部分输出或错误；不把 temperature=0 单独视为安全证明。不实施资源 ACL（保持 Planned）、新重排或生产启用。不改默认 local/Milvus Partial，不重建真实重要数据。开关关闭恢复原调用路径；重启清空进程缓存。没有并发合并请求的承诺，缓存不是外部一致性/多实例协调方案。

## 失败边界与反例清单

| 类别 | 必须纳入回归的反例 |
|---|---|
| 数值 | NaN/Infinity/极大或负 TTL、容量、temperature、max_tokens/timeout；无效得分、零/溢出向量不得通过旧缓存掩盖参数/身份变化 |
| 失败 | 超时、HTTP失败、空/截断响应、模型不匹配、流式取消/无DONE不存储；重试仍打后端 |
| 权限租户 | 跨租户命中、主体禁用/角色/上传者范围变更、授权回查失败，拒绝泄露 |
| 身份绑定 | 不同数据库、后端实现、模型/端点/凭据/Prompt/配置、索引激活或时间可见状态改变不能旧命中 |
| 回滚幂等 | 开关关闭及重启原路径；副本修改不污染；数据并发变化不写入；未完成流重入不得重放 |
