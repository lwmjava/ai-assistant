# RAG-030 对话父块受控组装 — 实施计划

> 日期：2026-10-09。依据：tasks.yaml 卡 RAG-030；ADR-0005 §4/§9；整改拆分计划 A4
> （`plan_rag_remediation_cards_20261005.md` 的 RAG-030 一节）。
> 依赖：RAG-016（搜索父块展开）、RAG-029（按块上下文组装统一入口）、RAG-026（uploader 范围贯穿检索），均已 done。
> 风险：L2。回滚：`RAG_DIALOG_PARENT_EXPANSION=False` 即回到子块 only 旧读路径。

## 1. 目标（原始契约）

授权 / 版本 / 注入复核后，按预算选入父块并去重，保留定位元信息。

验收：同步 / 流式实际上下文有父块；重复去重；他租户 / 历史 / 注入父块拒绝。

非目标：不只返回父块、不绕过预算与阈值。

## 2. 现状（代码事实，2026-10-09 核对）

| 路径 | 代码位置 | 父块展开现状 |
|---|---|---|
| 知识库搜索 API | `RAGService.search()`（`app/rag/service.py:740`）→ `backend.retrieve()` → `_expand_parent_chunks()`（`:786`） | **已展开**：Chunk/Document 双租户校验、软删、版本日期、index_id、uploader 范围过滤；注入剔除；按 `seen` 去重；父块带 `chunk_kind=parent`、`retrieval_origin=parent_expansion`、`expanded_from_chunk_id`、`score_inherited_from_chunk_id`，继承子块 similarity。 |
| 对话 / Agent 检索 | `RAGService.make_retriever()`（`:896`）→ `HybridRetriever`（`app/rag/retriever.py:106`）；`HybridRetriever.retrieve()`（`:134`）→ `backend.retrieve()` → 阈值过滤 `kept` → `format_context(kept)` | **未展开**：`last_hits` 只含阈值过滤后的子块。搜索路径的父块能力没有复用到对话路径。 |
| 上下文组装 | `assemble_retrieval`（`app/rag/retriever.py:44`）→ `build_context` / `_select_rag_blocks`（`app/rag/context_builder.py`） | 按块预算整块装入 / 整块丢弃；围栏闭合；回写 `last_selected` 与 `[资料 N]` / `_reply_sources` 三方对齐。预算与 selected 契约已就绪，**不感知父块来源**。 |

**缺口结论**：对话实际上下文（送模型的 RAG 段）目前只有子块；父块虽在搜索 API 展开，但 `make_retriever()` 没有把展开后的父块带进对话 `last_hits`。本卡把「已授权、已复核、已去重」的父块受控地接进对话检索结果，再由既有 Context Builder 按预算选入。

架构边界（ADR-0005 §4）：Context Builder 是纯函数、不直接访问数据库；父块回查仍留在 `RAGService._expand_parent_chunks`（Service 层，持 session）。本卡不新增 Context Builder 的 DB 直连，只把 Service 已有的展开能力作为回调注入 `HybridRetriever`。

## 3. 方案（最小改动，按契约不扩范围）

1. **`HybridRetriever.__init__`** 新增可选 `parent_expander` 异步回调
   （`Callable[[list[ChunkResult]], Coroutine[list[ChunkResult]]]`，默认 `None` = 旧行为）。
   协议：``expander(kept, *, query: str) -> list[ChunkResult]``，与 `RAGService._expand_parent_chunks` 签名对齐。
2. **`HybridRetriever.retrieve()`** 在阈值过滤得到 `kept` 之后、`_settle` 之前调用新私有方法
   `expanded = await self._expand_parents(kept, search_text)`：
   - expander 为 `None` 或 `kept` 为空 → 直接返回 `kept`（空命中不展开；后端异常时 `kept` 已为空）。
   - expander 正常返回 → 用其结果（已授权 / 版本 / 注入复核 + 去重 + 定位元信息）。
   - expander 抛异常 → 记一条 warning 日志并**回退到原 `kept`**（保留已通过 SQL 过滤与阈值的安全子块，不向上炸、不丢证据）。
3. `RetrievalOutcome.hits = expanded`（含父块）；`status` 仍按阈值 `classify(candidates=len(results), kept=len(kept))`——
   展开不改变 ok / below_threshold；`dropped_by_threshold` 仍只统计阈值丢弃。
4. 返回给 `assemble_retrieval` 的字符串也用 `expanded` 渲染（`format_context(expanded)`），使降级 snippet 与结构化结果一致。
5. **`RAGService.make_retriever()`** 在 `settings.RAG_DIALOG_PARENT_EXPANSION` 为真时绑定一个闭包 expander：
   闭包绑定 `index_id = self._read_index_id()`（与搜索路径同源），每把 `query` 透传给 `_expand_parent_chunks`；
   为假时 `parent_expander=None`（旧读路径）。
6. **新增配置** `RAG_DIALOG_PARENT_EXPANSION: bool = True`（回滚开关，写入 `config.py`，同步 `.env.example` 注释）。
7. Context Builder **不改动**：父块进 `last_hits` 后，既有 `_select_rag_blocks` 按 `RAG_CONTEXT_CHARS` 整块选入 / 整块丢弃，
   `last_selected` ↔ `[资料 N]` ↔ `_reply_sources` 三方对齐、围栏闭合、预算硬护栏全部自然成立。

### 不绕过阈值 / 预算的论证
- **阈值**：父块只在子块通过 `RAG_MIN_SIMILARITY` 阈值后由该子块触发；父块继承子块 similarity（`_expand_parent_chunks`），不单独评分、不单独进候选，因此不可能让低分文档的父块越阈进入。
- **预算**：父块与子块一样作为一个块进入 `_select_rag_blocks` 的顺序累加；超预算即整块丢弃（记 `REASON_BUDGET`），不截断、不补位。父块不占独立预算、不绕过 `RAG_CONTEXT_CHARS`。
- **不去重例外**：`_expand_parent_chunks` 已用 `seen` 保证同一父块只追加一次。

## 4. 非目标（Non-goals）

- 不把对话改成「只返回父块」——子块始终保留。
- 不改预算算法、阈值、RRF k、检索公式（RAG-005 基线冻结）。
- 不给 Context Builder 新增数据库直连；不新建独立 Reranker / Query Rewrite。
- 不改 Milvus、不碰 RAG-015 / RAG-032 / RAG-036 的代码与状态。
- 不做真实 Embedding / LLM 调用；不重建索引；不生产启用真实模型。
- 不改 `tasks.yaml`、不 git 提交（关闭登记由主 Agent 负责）。

## 5. 验收（可复现）

| 验收项 | 可观察期望 | 证据测试 |
|---|---|---|
| 同步 / 流式实际上下文有父块 | `make_retriever().retrieve()` 后 `last_hits` 含 `chunk_kind=parent`、`retrieval_origin=parent_expansion` 的父块；`build_context` 选入的 `last_selected` 含该父块（预算内） | `test_dialog_retrieval_expands_parent_into_last_hits` |

| 他租户父块拒绝 | 父块挂在他租户文档下 → 父块不进 `last_hits`，安全子块保留 | `test_dialog_cross_tenant_parent_rejected` |
| uploader 范围对父块生效 | uploader 模式下他人父块不展开 | `test_dialog_uploader_scope_applies_to_parent` |
| 历史 / 过期版本父块拒绝 | 非当前版 / 过期文档的父块不进结果 | `test_dialog_historical_parent_rejected` |

| expander 失败回退 | expander 抛异常 → 不向上炸、`last_hits` 回退为子块、status=ok | `test_parent_expansion_failure_falls_back_to_child_hits` |
| 开关关闭 = 旧行为 | `RAG_DIALOG_PARENT_EXPANSION=False` → `make_retriever().parent_expander is None`，结果子块 only | `test_dialog_parent_expansion_flag_off_keeps_legacy_path` |
| 定位元信息保留 | 父块带 `parent_id` / `expanded_from_chunk_id` / `score_inherited_from_chunk_id`；子块 `parent_id` 回填 | `test_parent_carries_positioning_metadata` |
