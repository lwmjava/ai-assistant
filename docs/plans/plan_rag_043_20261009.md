# RAG-043 实施计划：生成输出围栏与受限标识抑制

- 日期：2026-10-09
- 卡契约：`tasks.yaml` RAG-043（P1，depends_on RAG-035）
- 授权：用户 2026-10-09 批准开工；不发起未经授权真实模型调用。

## 1. 目标

在**生成/输出侧**建立确定性受限标识围栏：当模型输出披露受限标识（rag-036 的受限工号
`NW-HR-001`）时，检测并就地抑制（替换为占位符），使该标识不再到达用户、也不再被
RAG-035 零容忍规则判为泄露。rag-036 案例转绿或按拒答口径。

## 2. 现状（代码事实）

- 失败切片：`evals/reports/rag-v0.1-gen-real-20261009.json` rag-036，模型回答含 `NW-HR-001`，
  RAG-035 判定器零容忍捕获。根因：资源级 ACL（RAG-041）仍 Planned，检索把受限手册选入 selected；
  生成侧**无输出围栏**。
- 现有输出链：`app/security/output_filter.py::OutputFilter.filter()` 仅做有害内容正则 + `sanitized_text`
  字段（当前恒为原文副本）；`chat_service._apply_output_security` 只在 flagged 时告警，不回写脱敏文本。
- 受限标识事实：语料 `evals/fixtures/corpus/kb-hr-private.md` 明确「内部编制编号为 NW-HR-001」；
  rag-036 `forbidden_answer_points=["NW-HR-001"]`，`should_answer=false`。

## 3. 方案（确定性、零额外 LLM 调用、默认可关）

新增 `app/security/restricted_identifier_fence.py`：

- `RestrictedIdentifier(id, pattern)`：注册表项，`id` 为键，`pattern` 为编译正则。
- 内置注册表 v0.1：种子 `NW-HR-001`（case-insensitive；分隔符容忍 `- _ 空白` 变体；
  前后边界锚定，避免误伤合法相似 ID）。
- `RestrictedIdentifierFence(registry=None, *, enabled=True, replacement="[受限内容已屏蔽]")`：
  - `filter(text) -> FenceResult(flagged, hits, redacted_text)`；
  - 命中即把所有匹配替换为 `replacement`，记录命中的注册表 id；
  - `enabled=False` 时原样返回、不命中（独立关闭/回退）。
- 集成：`OutputFilter` 接受可选 `restricted_fence`；传入时在 `filter()` 中跑围栏，命中则把
  `restricted_id_leak` 加入 matches/reasons、`sanitized_text` 改为脱敏文本。
  chat_service 现有 `OutputFilter()` 无参构造 → 默认不接入围栏（向后兼容，RAG-040 先例：
  模块未接线主链路＝预期默认关闭，接线属另卡）。

不引入新 LLM 调用；不改 `app/core/config.py`（无新开关）；不改检索 ACL（RAG-041）。

## 4. 非目标

- 不实现检索侧资源 ACL（RAG-041）。
- 不用 Prompt 提示替代硬边界。
- 不把 chat_service 响应回写脱敏文本（live 接线）作为本卡交付——围栏组件与 E2 回归为交付；
  live 回写属另卡，范围决策见实现说明。
- 不改 `.env`、冻结基线、生产数据、RAG-015/032/036。

## 5. 验收（对照卡 acceptance）

1. 围栏规则生效（E2：隔离/合成 + 真实 rag-036 回答文本重放）。
2. rag-036 经围栏后零容忍转绿（`NW-HR-001` 被屏蔽，判定器不再命中）。
3. 规则可独立关闭/回退（`enabled=False` 原样返回）。
4. 无凭据/敏感信息外泄；调用受预算（零额外模型调用）。

## 6. 失败边界清单（每类至少一反例测试）

- **数值边界**：空文本/无命中；多 occurrence 全部替换；超长输出截断不破坏围栏。
- **失败路径**：围栏内部异常不污染原文（fail-open 不崩）；注册表为空 = 不命中。
- **权限与租户**：受限标识仅抑制受限标识本身，不误伤同形态合法 ID（`NW-PRINT-X1` 打印机型号必须保留）。
- **身份与绑定**：命中记录带注册表 id；围栏实例可独立替换（不污染全局单例）。
- **回滚与幂等**：`enabled=False` 关闭后原文不变；重复替换幂等（替换后文本不再含原标识）。
- **本卡特有**：
  - 受限标识定义与存储：注册表可注入、内置种子含 NW-HR-001。
  - 多格式匹配：`NW-HR-001` / `nw-hr-001` / `NW HR 001` / `NW_HR_001` 均命中。
  - 误伤正常内容：合法 `NW-PRINT-X1`、价格、普通数字不被屏蔽。
  - 变体逃逸：大小写/分隔符变体不漏。
  - 规则降级：围栏异常或关闭时输出安全链不崩。
  - 默认关闭回滚：未注入围栏的 `OutputFilter()` 行为与现状一致。
