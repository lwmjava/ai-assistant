## 0. 读法

| 列 | 含义 |
|---|---|
| 人时 | 单人实现+测试+实现说明的中位估算；含小缓冲，不含开会与阶段 0 产品会 |
| 重要性 | `阻断`=挡发布门禁或安装主路径；`高`=P0 功能/安全/数据；`中`=P1 或可并行；`低`=P2 但仍锁进 1.0 |
| yaml 依赖 | `tasks.yaml` 的 `depends_on` |
| 阶段序 | 锁定计划阶段内顺序；同阶段可按依赖并行 |

合计人时是**串行上界参考**。日历仍以锁定计划阶段窗口为准；人时超出窗口则阶段日期整体后移，不删锁定项。
