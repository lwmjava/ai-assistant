## 1. 口径

| 词 | 含义 |
|---|---|
| `锁定` | 进锁定计划阶段 1～7，且 `tasks.yaml` 有卡（或明确并入某卡） |
| `1.0 不做` | 不进 `v1.0.0` 锁定；打标后再排或已取消 |
| `未核对` | 差距表第 4 节；不能开卡、不锁 1.0 |
| `汇总` | 本行是验收篮子，拆到多卡；不单开卡 |

**有效标准**：是否锁 1.0 → 看差距表「1.0 关系」+ 锁定计划阶段表，**不**单看「级别」列。
