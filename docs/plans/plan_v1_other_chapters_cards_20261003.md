### 2.1 `CLI-003`

- 问题：`CLI-001` 只做 migrate 与创建管理员，明确不做 start/stop/logs。
- 交付：`start`、`stop`、`status`、`logs` 可调用；与 README 一致。
- 非目标：不重做 migrate/admin；不实现 K8s。
- 验收：本机用这四条命令能启停并读到状态与日志；失败时有可读原因。

### 2.2 `FLOW-004`

- 问题：开关默认关；未装 croniter 时调度不跑，页面未说明只剩手动。
- 交付：打开后定时路径可用（依赖 `FLOW-003` 到点能力）；未装可选依赖时页面写明只剩手动执行。
- 非目标：不做重试（`PWFL-001`）；不替代到点触发卡。
- 验收：关闭时不自动跑；打开且依赖齐全时到点可触发；缺 croniter 时页面有说明。

### 2.3 `EVO-002`

- 问题：`EVO-001` 只锁反思与蒸馏记录，明确不把反思改成技能；差距表仍缺改技能与待办提取。
- 交付：开关打开时，反思结果可生成技能候选或待办，并留下可查记录。
- 非目标：不在默认关闭时算完成；不自动无审上线技能。
- 验收：一次对话后有技能候选或待办记录；需人工确认后才生效的路径写清。

### 2.4 `ADM-006`

- 问题：前端无 `/app/settings/tenant`；`ADM-004` 非目标写不做租户设置页。
- 交付：租户管理员在该页管理本租户成员与知识库（ADM-04）。
- 非目标：不做系统级四页重做；不做多副本汇总。
- 验收：tenant_admin 可进入并完成成员/知识库管理；其他角色按矩阵拒绝。

### 2.5 `ADM-007`

- 问题：需求 ADM-05 要求可配置 Feature Flag；v1.0 约定只提供 API。
- 交付：`GET`/`PATCH` 管理 Feature Flag；库表或等价存储可覆盖代码默认值。
- 非目标：不做监控大盘可视化；不做 EE License 解锁全集。
- 验收：system_admin 可切换；未授权拒绝；重启后状态保持。

### 2.6 `SEC-007`

- 问题：`SECURITY_BLOCK_ON_INJECTION` 默认 false，检测到只告警。
- 交付：配置为阻断时，注入请求被拦住且不进入后续管线。
- 非目标：不改默认仍可告警不阻断；不在本条重做脱敏。
- 验收：打开阻断后，构造注入样例返回稳定错误且无助手落库成功回复；关闭时行为与现网一致。

### 2.7 `NFR-013`

- 问题：密钥形状半边已在差距表核对；硬编码 URL 半边未扫，不能把 §4.5 第 10 条整条写成通过。
- 交付：对 `app/`、`frontend/src/`、编排文件做硬编码 URL 扫描，并纳入 CI 或 pre-commit。
- 非目标：不替代 `NFR-006` 的密钥与依赖漏洞；不误杀文档中的示例域名而不给白名单。
- 验收：故意放入的硬编码内网/生产 URL 被拦截或报告；白名单外命中导致门禁失败。

### 2.8 `DOC-001`

- 问题：仓库没有 CHANGELOG；§6.7 要求不兼容变更写入 Breaking 区。
- 交付：建立 `CHANGELOG.md`，含 Breaking 区约定；与版本升级说明交叉引用。
- 非目标：不代替 `OPS-003` 的升级回滚演练本身。
- 验收：文件存在且含 Breaking 区标题；`OPS-003` 演练记录可链到该区。
