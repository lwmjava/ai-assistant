日期：2026-10-29。用户批准将当前全部未完成任务纳入 1.0，并以核心产品能力优先、上线运维后置的顺序推进。

## 1. 范围与授权

- 冻结当前 43 项未完成任务，全部目标版本为 1.0。175 项 done 与 1 项 cancelled 的状态和关闭结论不改；已取消项不自动恢复。
- 原有 14 张本地新增拆分卡保留编号与契约，纳入本次范围，不另建重复任务。

- 从 `develop` 创建独立任务分支，完成验证、审查与验收后先合入 `develop`；项目全部任务完成且用户最终验收后，再按授权合入 `main`。
