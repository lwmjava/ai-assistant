# 裁决记录：测试用户用标记而非角色（2026-10-04）

> 状态：已写入需求、差距表、`INST-004`。未改业务代码。

## 裁决

采用 **角色管权限 + `is_test_user` 标记管是否测试账号**，二者分开。

| 规则 | 内容 |
|---|---|
| 角色 | 仍为 system_admin / system_viewer / tenant_admin / member / viewer，只决定能做什么 |
| 标记 | 用户上布尔字段 `is_test_user`（名称以实现为准，语义固定） |
| 内置 `culture` | 租户角色为 `member`（或实现时等价业务读写角色），且 `is_test_user=true`；可无邮箱 |
| 后续 | 管理员可将任意用户的 `is_test_user` 打开或关闭，以区分普通用户与测试用户；不因此改角色矩阵列 |
| 导出/统计/清理 | 凡依赖「是否测试数据」的路径，以 `is_test_user` 为准，不以用户名是否为 `culture` 为准 |

## 非目标

- 不新增 `test_member` 角色。
- 不在本裁决实现导出排除逻辑的全部产品细则；`INST-004` 至少落库标记并保证 `culture` 带标记。
