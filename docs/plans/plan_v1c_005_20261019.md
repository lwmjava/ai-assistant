## 2. 现状与方案取舍

事实：route_message 同时命中时工具优先；fast.tools 显式使用 retriever=None。默认 self 在固定参数 Plan v1 生成之后才检索，_build_plan 没有检索正文，无法证明计划参数来自本轮资料。已有 Supervisor 受控委派仍不包含资料参数提取。ADR-0011 不允许动态步骤参数引用，ADR-0013/0015 刻意保留组合任务给本卡。

- A，推荐：请求内固定组合 helper，在 self/langgraph 分岔前接入；复用检索/Context Builder、执行器及安全回调，同步/流式共享一个迭代器。只改变显式组合请求。
- B：把所有检索提前到 Plan 前，再给工具短路补检索。会改变旧计划输入、恢复时机，而且参数来源门禁仍需另做，不采用。
- C：Plan v2 动态参数依赖。需要更大状态兼容和恢复设计，超出本卡，不采用。

保留既有普通问答、单独工具、单独 RAG、Supervisor 和 Plan v1/checkpoint；组合 helper 不成为另一套通用 Runtime/Executor。

## 3. 流程与代码边界

```text
ChatService 原安全/身份/消息/技能
  → 只按当前安全用户消息识别知识库+工具意图
  → 固定组合迭代器（chat 与 chat_stream 共用）
      → 原 ChatRetriever.retrieve（至多一次）
      → assemble_retrieval / 本轮 last_selected
      → 严格来源参数提取（至多一次模型逻辑调用，有限物理fallback另计）
      → 代码验证事实片段、数值与表达式
      → 原 ToolExecutor（至多一次逻辑工具请求）
      → 确定性回答模板 + 真实结果/来源披露（不再调用回答模型）
  → 原输出安全、消息持久化、来源回查与事件
```

Service 负责 Session/主体/租户检查与回调装配；Agent helper 只消费授权后的检索钩子、选块、模型、工具与回调，不访问数据库。已有 Supervisor 装配内的主体复核可抽成同文件可复用工厂，不复制权限规则。保留原 RBAC、ToolContract、审计与技能白名单交集；每次实际执行/重试前及 tool.call 事件让出控制后重新复核主体和技能。

组合判定是显式、保守的当前消息规则：同时要求私有知识/文档依据与计算/工具动作；补充受此双重条件约束的“按报销标准计算”等表达，不给普通“计算”一词全局开工具。历史、附件正文、技能和检索内容不能授予组合或工具权限。多轮省略表达不假装已被通用语义识别。

## 4. 参数与来源门禁

1. 检索必须明确 ok，Context Builder 后实际选块非空；RAG关闭、未命中、低分、初始化失败或没有完整选块时，零工具调用并固定说明原因。只有字符串的兼容 Retriever 不足以证明可执行资料，组合路径拒绝执行，不改变旧问答兼容。
2. 一次提取输出严格版本化 JSON：事实列表使用有限标识、source=user/chunk、chunk_id（资料事实）、start/end、quote、数值及单位，并给出只引用事实标识的算式。拒绝未知/重复键、超深/超长/非有限数值和无来源事实。事实最多16条、表达式最多64节点/深度8，完整提取 JSON 最多16KiB。
3. 代码核验引用属于本轮 last_selected，quote 等于本轮安全可见文本的精确切片；用户事实仅从当前安全用户目标取。数值从 quote 的明确数字解析并核对，不直接相信模型 value。裁剪后正文与原块 offset 不混用，选入正文之外的文本不得当依据。
4. 算式只允许绑定标识和加减乘除、括号，禁止自由数值常量、属性、函数调用、幂、下标与任意代码。验证后由代码替换经过核验的数值，构造现有 calculator.expression；用有限 Decimal/AST 边界检查防止 NaN/Infinity、过大数、除零等输入。
5. 所有声明事实必须被算式实际消费，至少一条来自本轮chunk；重复事实、未使用事实、仅用户数据参与算式均拒绝。天数/人数等缺失、多个冲突标准、单位无法一致解释、解析失败则澄清并停止，不猜值、不自行补规则。精确引用与数值匹配不等于完整政策语义已被数学证明；版本化业务案例必须覆盖政策选择/金额/来源准确性，不能声称支持任意复杂规则。

### 数值和单位的可执行约束

- 首轮数字仅允许普通阿拉伯十进制（整数部分最多12位、小数最多4位，绝对值≤10^9）；拒绝科学计数、千位分隔、中文数字、百分率与隐式换算。费用/费率非负；人数和天数为严格正整数；bool不是数值。
- 单位只支持人民币元、人、天，以及元/人、元/天、元/人/天。代码从明确包含数字与单位的原文片段识别；“每人”“每日/每天”等限已声明词法。不同币种、小时/夜等换算、无单位或难以判定费率分母时澄清，不让模型单独宣称单位一致。
- 加减要求同维度，乘除按元/人/天三维指数归约；最终必须是元，不能把元/天当总金额。每个中间值为有限数且绝对值≤10^12，Decimal预检精度28，除零拒绝；上下界和词法均由代码检查。
- 保留真实calculator的int/float行为，不替换工具实现。Decimal预检仅作一致性门禁：工具成功后严格读取其实际有限数值，实际值与预检值分别按ROUND_HALF_UP保留两位，只有二者一致才输出该金额；不一致判为结果不一致，固定失败说明，不用预检值冒充工具结果、不自动重算。输出金额唯一来源仍是通过一致性门禁的实际工具结果。覆盖0.1+0.2、小数舍入及大幅值误差反例。

## 5. 有界执行、失败、缓存与兼容

- 组合阶段最多1次检索、1次提取模型逻辑调用、1次逻辑计算器执行，最终回答使用确定性模板，不另调回答模型；原记忆压缩和技能匹配的既有调用另按用途计数，不将此上限冒称整个HTTP请求仅一次模型调用，不为坏输出重提案；工具自身重试沿既有有限契约，并占用同一请求预算。零工具预算不启动工具。提取沿用现有受控 provider/options/token预算及有限fallback；分别记录逻辑调用与实际物理尝试，非法超时配置拒绝，不新增全局开关。
- 工具或提取失败后不让模型编造金额；资料无依据不使用常识或 web_search 补造企业标准。成功回复全部使用确定性模板，仅含已校验事实、实际工具金额和本轮资料来源；不拼接自由模型解释，避免正确摘要旁再出现伪造金额或来源。流式在验证完成前不得吐金额，完成后按原token事件分块发模板。工具返回失败不映射成功；来源、验证事实和实际执行状态分别追踪，Trace/审计仅写安全标识、状态和摘要，不写原始敏感正文。
- 参数引用不能扩大工具授权；SkillRuntime 的版本/撤权/私有围栏仍检查。未授权或不支持的工具请求零执行，失败与未调用分别披露。
- 取消或 GeneratorExit 显式关闭内层迭代器，停止后续阶段；工具在途沿既有取消/审计语义，不承诺撤销已经发生的操作。
- 模型缓存不能缓存工具成功事实；每个请求重新检索、选块验证和鉴权并真实执行。提取缓存必须绑定主体/租户/技能版本/选块内容摘要/协议版本；现有缓存如不能证明隔离，局部 bypass 提取调用并记录，不关闭全局缓存。
- 附件不阻止按当前用户目标识别组合，但附件不能作为授权或企业规则替代。重新生成仍经过原消息权限、原附件与成功提交规则。显式恢复旧 Plan v1 仍走旧入口；新组合不伪装为 Plan v1 checkpoint，不自动恢复/重放，明确拒绝组合 resume。此限制需批准 ADR-0016。
- 复用原 tool/node/citations/sources/done 事件与消息来源字段，不增加 API/schema、前端或状态表。若实现发现必须扩外部契约，先申请具体路径，不自行改前端或接口。

## 7. 失败边界与 Evaluation

版本化数据分类 Silver/Adversarial/Observed Regression/Smoke，AI 编写不标 Gold。不修改冻结 agent/rag official 数据，不用 holdout 调参。

| 类别 | 必须构造的反例 | 期望 |
|---|---|---|
| 数值 | NaN/Infinity/bool、过大数/深度、除零、缺人数天数、单位冲突/维度不归约为元、混币/百分率/换算、小数金额不一致、重复或未用事实/仅用户事实、自由常量 | 前置非法输入零工具调用；实际值与预检金额不一致时已调用一次，保留审计但不输出成功金额；无伪造金额 |
| 失败 | RAG关闭/no_hit/低分/unavailable、选块预算不足、提取超时/坏JSON、计算器业务错误/超时、提取fallback耗尽/确定性渲染失败 | 真实状态可见，后继受阻，来源与审计不残留旧请求 |
| 权限租户 | 跨租户资料候选/伪造chunk ID、User/Tenant停用、角色/token变更、技能版本/工具限制变化 | 无泄漏/越权/后续启动，独立Session核验 |
| 身份绑定 | 索引/provider身份不符、错误Session绑定、引用非本轮选块/裁剪外正文 | 保留原索引保护；错误来源不得形成参数 |
| 注入 | 资料诱导web_search/代码、篡改system、要求替换原用户目标、工具输出伪造成功 | 授权集合和真实终态不可被资料改写 |
| 生命周期 | tool.call让出后撤权、检索/模型/执行取消、外层流close、已完成后重入 | 零后继，不自动重放，状态和审计一致 |
| 缓存回滚 | 相同候选新请求、不同tenant/资料/技能版、旧Plan v1恢复、regenerate失败 | 新请求真实执行；不读旧结果；原恢复路径保留；原消息不被失败覆盖 |
| 兼容 | self/langgraph、chat/stream、普通/工具/RAG/多轮、附件 | 组合不被互斥短路，单一请求保持旧行为 |

成功示例：私有规则明确“住宿每人每日300元、餐补每人每日80元”；当前用户明确“1人3天，按此标准计算”。必须实际检索并取本轮规则、核验 300/80 与用户1/3的来源、真实计算 `(300+80)*1*3=1140`，来源与数值共同返回。模板不是生产报销裁决，不涵盖税费/封顶等未给条件。
