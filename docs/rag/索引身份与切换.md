# Embedding 索引身份与受控切换（ADR-0008 / RAG-032）

日期：2026-10-07
代码：`app/rag/index_identity.py`、`app/rag/index_registry.py`、`scripts/rebuild_embedding_index.py`

---

## 1. 为什么需要索引身份

向量的可比性不只取决于维度。**同维度不同模型产出的向量空间互不通用**；
归一化与度量约定变了，数值同样不可比。改造前只有三处零散的维度校验，
而最关键的检索过滤用的是「本次查询向量的长度」——同维异模型时长度相同，
这条分支根本不会触发，混用是静默发生的。

```
改造前：len(查询向量) != len(分块向量) → 跳过
        同维异模型 → 长度相同 → 不跳过 → 混用（静默）

改造后：索引登记 dim / provider / model / version / normalization / metric
        查询按「生效索引」过滤，维度以索引登记为准
        身份不符 → 拒绝（写入抛错，检索判 unavailable）
```

## 2. 身份包含什么

`EmbeddingIndexIdentity`（`app/rag/index_identity.py`）：

| 字段 | 来源 | 为什么必须绑定 |
|---|---|---|
| `backend` | `RAG_VECTOR_STORE` | local 与 Milvus 是两套索引 |
| `provider` | provider 类名 | Mock 与真实模型产出的向量不能混 |
| `model` | provider 的 `model` | 换模型即换向量空间 |
| `deployment` | provider 显式声明，**缺失留空不猜** | 同模型不同部署也可能不同 |
| `dim` | provider 的 `dim` | 基础校验 |
| `index_version` | `EMBEDDING_INDEX_VERSION` | 显式版本，重建时递增 |
| `normalization` | `EMBEDDING_NORMALIZATION` | 影响向量数值 |
| `metric` | `EMBEDDING_METRIC` | 影响相似度语义 |

**身份里不含密钥与连接串**，可以安全落库、落日志、进 health 响应。

## 3. 存储

新表 `rag_embedding_indexes`（迁移 `b2c3d4e5f607`），
`rag_document_chunks` 新增 `index_id`（**可空** —— 历史行没有身份）。

状态机：`preparing → active → retired`，失败为 `failed`。
**旧索引只转 `retired`，不删**，保留回退能力。

## 4. 三个校验点

| 位置 | 行为 |
|---|---|
| 写入（`service.py` 摄取与重解析） | 落 `index_id`；目标索引身份与当前模型不符 → 抛 `IndexIdentityError` |
| 检索（`local.py`） | 只查生效索引名下的分块；查询向量维度与索引登记不符 → 抛错（上层收敛为 `unavailable`） |
| 切换（脚本 `activate` / `rollback`） | 校验当前配置与目标索引身份一致，不一致直接拒绝 |

最后一条是 ADR-0008 的硬要求：**回退不能只改集合名而仍用新模型查旧向量**。

## 5. 历史数据怎么办（重要行为变更）

`index_id IS NULL` 的历史分块**默认不参与检索**。这是有意的收紧：
ADR-0008 明确禁止自动认定历史索引与当前配置兼容——维度相同不等于模型相同。

它们不是被删掉，而是被隔离：

- `/api/health` 的 `checks.vector_store.embedding_index.legacy_chunks` 暴露数量，不静默
- 要纳入当前索引：`python scripts/rebuild_embedding_index.py adopt --confirm`
  —— 必须显式确认，且**全部历史分块维度抽样必须与索引登记一致**，
  有一条对不上就整体拒绝、不写一半
- 更彻底的做法：`rebuild --apply` 用摄取快照全量重建（会调用嵌入接口，产生费用）

**升级前已存在的知识库，在登记或重建之前会查不到东西。** 这是预期行为，不是 bug。

## 6. 切换流程

```bash
# 1) 登记新索引（不切换，旧索引继续服务）
python scripts/rebuild_embedding_index.py prepare --model text-embedding-v4 --dim 1024

# 2) 全量重建（读摄取快照回放，不需要重新上传源文件）
python scripts/rebuild_embedding_index.py rebuild --apply

# 3) 校验通过后显式激活（旧索引自动转 retired）
python scripts/rebuild_embedding_index.py activate --index-id <id>

# 出问题回退
python scripts/rebuild_embedding_index.py rollback --index-id <旧索引 id>
```

`rebuild` 失败时索引标记 `failed`，**旧索引仍为 active，读路径不受影响**。
