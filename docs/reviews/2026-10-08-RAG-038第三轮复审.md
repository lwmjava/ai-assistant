## 3. local.py 的 659 行 diff 是不是夹带改写

  `_hybrid_search_sync(...)`，async 入口改为 `await asyncio.to_thread(self._hybrid_search_sync, ...)`。

  as_of/schedule_at/read_scope/identity），没有夹带其它逻辑改动。

  （`core.autocrlf=false`）。这是编辑器落盘造成的行尾漂移，使 diff 从 33 行膨胀到 659 行，
  会污染 git blame。Python/ruff/mypy 均不受影响。**建议提交前把该文件归一化回 LF。**

权限过滤逐条核对（`_hybrid_search_sync` 体内，186–310 行）原样保留：

  文档已如实记录。
