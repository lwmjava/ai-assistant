# PROMPT-001 审查缺陷与修复计划

日期：2026-10-11；发现于初版版本工具，最终状态以独立复核报告为准。

| 缺陷 | 证据与影响 | 修复与正式回归 |
|---|---|---|
| F01 / P2 配置拼写错误静默丢弃 | 独立审查 Agent 新进程传入 LLM_DEFAULT_MODLE 后退出 0，登记默认模型而非预期变更 | 拒绝未知键；只允许明确列出的秘密字段被排除；反例不得输出输入值 |
| F02 / P2 配置类型和数值边界不完整 | 初版接受负 max_tokens，check 对非对象输入缺少入口类型检查 | 校验对象、有限数值与合法范围，拒绝 bool 冒充整数；CLI 坏输入非零且无堆栈 |
| F03 / P2 生效时间可接受日期而非 UTC 瞬间 | 初版只检查 Z 后缀并 fromisoformat，可能解析为无时区 datetime | 严格 UTC 时区、日期时间格式，反例拒绝只有日期或含偏移伪 Z |
| F04 / P2 配置依据原文可能含秘密 | LLM_CAPABILITY_DECLARED_SOURCE 为任意字符串，初版放入导出字段白名单 | 秘密/端点/依据不输出原文；采用摘要或安全限制，注入含凭据来源的反例 |
| F05 / P2 Git 来源身份仅格式校验 | 原始 source_commit 只验证 40 字符，不能证明当前文件属于该提交 | 明确来源是变更基点，当前版本绑定源摘要；验证可解析 Git 基点或提供隔离副本基点核对；不得宣称未提交快照已在基点存在 |
| F06 / P2 配置源读取先于路径护栏 | 主 Agent 读调用顺序发现 defaults 在 source_inventory 之前读取 config.py，符号链接逃逸可能先读越界源再拒绝 | AST 读取前验证解析路径留在指定根且源不是符号链接，补正式反例；不依赖后续扫描补救 |

修复顺序：先补正式反例，再修复 F01/F02/F03/F04；F05 对照本卡“来源”要求明确语义并增加可核对的证据/说明；随后重跑本卡测试与受影响回归，独立入口复核，记录最终指纹。不得删失败用例、放宽范围、改写默认 Prompt 或模型路由。
