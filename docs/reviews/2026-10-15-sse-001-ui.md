# SSE 页面操作证据

日期：2026-10-15，Asia/Shanghai。操作者：Codex 主 Agent，通过 cua_repl 的真实浏览器 UI；未使用直接 API 请求冒充页面操作。

## 环境与边界

当前编译的 frontend/dist，由真实 FastAPI 应用在 http://127.0.0.1:18765 托管。临时 SQLite 位于 data/pytest-tmp/sse-ui-*/ui.db；真实 get_current_user/JWT/角色依赖与 ActiveRun 复核仍执行。为避免输入或读取任何真实口令，只有隔离夹具中的 authenticate 被替换为固定测试身份，登录框文本是被忽略的无敏感占位内容。这不证明密码认证正确，不替代 INST-004 真实改密页面验收。

LLM 和 Embedding 均为 Mock，禁止非 loopback DNS/socket；不读工作区 .env，不使用业务库、真实文档或真实模型。复现慢流夹具：D:\DepTooL\anaconda3\envs\ai-assistant\python.exe -u -m tests.manual_sse_ui。夹具仅监听 loopback、每次新建测试库，不能作为生产登录配置。

## 实际步骤与结果

1. 打开 /login，使用 ui-fixture 隔离身份进入 /chat，页面显示后端在线及无真实模型提示。
2. 发送合成消息“你好，检查隔离流式回复”。页面先出现停止按钮与阶段状态，随后显示 Mock 完整回复及知识库无命中的披露语；终态恢复发送按钮。原生工具已记录页面截图。
3. 第一次停止尝试碰到运行已完成，界面展示完整结果，未虚称取消成功。为可复现主动停止，换用每字符延迟 0.8 秒的 tests.manual_sse_ui，使用全新临时库重新登录。
4. 发送“验证停止后保留部分回复”，实际看到意图 full、可展开执行步骤（1）、节点阶段与停止按钮；点击停止，收到取消确认后界面保留“隔离界面验证回复：流式事件到达”部分文本并显示“已停止”，不补成完整句子。
5. 刷新浏览器。从可见“打开会话列表”入口展开抽屉，再打开刚才的会话。新页面读取的历史消息仍是同一部分文本，状态仍为“已停止”，模型标签为 mock-model；不是旧 React 对象缓存。
6. 浏览器 dev.logs 读取 error 级别结果为 []。成功与停止/刷新后的原生截图和 AX/DOM 状态保存在本次工具历史，没有编造文件链接。

UI 曾在抽屉关闭时点击不可见列表项而没有改变页面；随后按截图明确展开可见列表再选择，才完成第 5 步，不把无效果点击算成功。

## 未证明项

浏览器未主动制造底层断网或缓冲过期；单次 GET 重连、Last-Event-ID、缺号拒绝、首响应/心跳超时、401 刷新、回放 409 和旧回调隔离由独立传输/Hook 测试证明，不把这些单测写成已浏览器断网实演。真实提供商、HTTPS、Linux、同提交 CI 和人工业务判断未验证。

已观察既有时间显示偏差：乐观消息显示本地时间，服务端持久化后以少 8 小时的时间显示，列表出现“8 小时前”。本卡未改变日期格式工具，不顺手扩展任务；此记录不宣称时间问题已修。

这是 SSE 阶段候选的页面证据。后续 LLM/附件及最终输入变化后，受影响页面仍需重新验证，不能直接用于关闭新的候选版本。
